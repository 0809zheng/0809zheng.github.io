# 1. 基因组学

<a id="s-1-1"></a>
## 1.1 DNA 分词与基础模型

<a id="p-001"></a>
### ⚪ **dnaHNet / DNAChunker / LDARNet**：DNA 序列的动态分块与可学习分词
- **paper**：[**dnaHNet: A Scalable and Hierarchical Foundation Model for Genomic Sequence Learning**](https://openreview.net/forum?id=6pN2KNCspk)
- **paper**：[**DNAChunker: Learnable Tokenization for DNA Language Models**](https://openreview.net/forum?id=1DxD3SBid1)
- **paper**：[**LDARNet: DNA Adaptive Representation Network with Learnable Tokenization for Genomic Modeling**](https://openreview.net/forum?id=v4hQnJn6aN)

DNA 序列没有天然的词边界：固定 k-mer 或 BPE 分词容易切断调控元件，而单碱基分辨率计算开销太大。这三篇工作同时引入了 **H-Net** 的“编码器—主干网—解码器”动态分块（Chunking）架构，在预训练中端到端学习分词边界。三者共用同一套核心机制：

1. **余弦不相似度路由**：外层轻量编码器（Mamba 系列）提取单碱基隐状态 $h_t$，线性投影为 $q_t, k_t$ 后，用相邻位置的余弦不相似度计算切分概率 $p_t$ 并采样硬边界指示符 $b_t\in\{0,1\}$：
   $$p_t = \frac12\big(1 - \mathrm{CosineSim}(q_t, k_{t-1})\big), \quad b_t = \mathbf{1}[p_t > 0.5].$$
   只有 $b_t=1$ 的位置会被保留送入深层主干网络，反向传播配合直通估计器（STE）回传梯度。
2. **平滑解块（Dechunking）**：主干网处理完压缩序列后，解码器以边界概率 $p$ 为门控对相邻 chunk 做 EMA 线性递归平滑，再按累计边界计数索引 $j(t)=\sum_{k=1}^t b_k$ 广播复制回原始碱基长度 $L$。
3. **压缩率约束（Ratio Loss）**：设第 $s$ 级的目标压缩比为 $R_s > 1$（即目标保留率为 $1/R_s$）。为防止路由退化为全选或全不选，引入辅助损失约束实际离散选中率 $F_s=\frac{1}{L}\sum_{t=1}^L b_t^{(s)}$ 和平均边界概率 $G_s=\frac{1}{L}\sum_{t=1}^L p_t^{(s)}$ 趋近目标保留率 **$1/R_s$**（求导时 $F_s$ 视为常数，$\frac{\partial\mathcal L_{\text{rate}}^{(s)}}{\partial G_s} \propto R_s F_s - 1$，当 $F_s = 1/R_s$ 时梯度为零）：
   $$\mathcal L = \mathcal L_{\text{LM}} + \lambda \sum_s \frac{R_s}{R_s-1}\Big((R_s-1)F_sG_s + (1-F_s)(1-G_s)\Big).$$

三篇工作的区别主要在训练范式和防信息泄露设计上：

#### 1. **dnaHNet**
![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-001-dnahnet.png)
采用**单向自回归（NTP）**训练，编解码器为因果 Mamba + 滑窗 Transformer。设计了两级压缩（$R_1=3, R_2=2$），第一级对齐三联体密码子，第二级捕捉密码子对偏好。自回归推理时按需触发：只有采样到 $b_t=1$ 时才调用主干网络更新分布。

#### 2. **DNAChunker**
![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-003-dnachunker.png)
采用**双向掩码建模（MLM）**（BiMamba 编解码 + 双向 Transformer 主干）。为了防止 `[MASK]` 破坏动态分块或通过跳跃连接泄露邻近碱基信息，做了两点专门设计：（1）**Mask Protection**：在每个 `[MASK]` 前后强制切出硬边界，保持为独立单例 token；（2）**Masked Residual Gating**：将包含 `[MASK]` 的编码器同级残差连接强制置零，迫使预测信息必须经过深层主干网络。

#### 3. **LDARNet**
![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-004-ldarnet.png)
同样做双向 MLM，但采用**纯 BiMamba-2 主干**（单级压缩，无全局 Transformer）。为了消除双向建模的方向偏置，路由时同时计算前向与后向余弦相似度的均值 $\bar s_t = \frac12(\cos(q_{t-1},k_t) + \cos(q_t,k_{t-1}))$，解块时也采用前向与后向双向对称 EMA 平滑。

<a id="p-002"></a>
### ⚪ **BioToken / BioFM**：把基因注释和遗传变异直接写进词表
- **paper**：[**BioToken and BioFM – Biologically-Informed Tokenization Enables Accurate and Efficient Genomic Foundation Models**](https://openreview.net/forum?id=Vmt2iPfH5z)

纯 DNA 序列模型缺乏基因结构和个体变异上下文。**BioToken** 直接通过扩展词表把生物学先验塞进序列里：用特殊变异词元 $\check{\mathrm{A}},\check{\mathrm{G}},\check{\mathrm{C}},\check{\mathrm{T}}$ 替换单核苷酸变异（SNV）或插入位点；用成对的起止特殊词元直接标出 GENCODE 注释的转录本、外显子和 CDS 边界。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-002-biotoken.png)

基于该词表，作者在千人基因组数据上用自回归损失 $\mathcal L=-\sum_t\log p_\theta(x_t\mid x_{<t})$ 训练了 Transformer 解码器 **BioFM**（其中 $x_t$ 可为普通碱基、变异词元或注释词元）。做下游变异效应预测时，为弥补单向因果模型的限制，分别截取以变异位点为终点的上游正向序列和下游反向互补序列提取末位特征，再将参考与突变特征拼接 $[\mathbf{e}^{\text{ref}} \parallel \mathbf{e}^{\text{mut}}]$ 送入分类器。

<a id="p-005"></a>
### ⚪ **OpticalDNA**：把 DNA 渲染成图片，用视觉文档模型做基因建模
- **paper**：[**Rethinking Genomic Modeling Through Optical Character Recognition**](https://openreview.net/forum?id=nggzekChuU)

长基因组中夹杂着大量低信息密度的背景区域，一维模型逐 token 扫描开销极大。**OpticalDNA** 将一维长 DNA 序列按行连续渲染成多页 RGB 图像文档 $\{\text{page}_p\}_{p=0}^{P-1}$，记录每个碱基的像素边界框，把一维序列区间映射为二维页面区域。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-005-opticaldna.png)

视觉编码器 $E_\theta$ 提取图像 patch 特征并做卷积下采样与跨页注意力池化，压缩为定长视觉表示 $Z\in\mathbb R^{L\times d}$，再交给 MoE 自回归解码器 $G_\psi$ 在指令 $q$ 条件下生成输出序列 $\hat Y = (\hat y_1, \dots, \hat y_T)$，完成 6 类 OCR 预训练任务（全文/逐行/ROI 框转录、涂白补全、子序列定位、染色体分类）：
$$P_\psi(\hat Y\mid Z,q)=\prod_{t=1}^{T}P_\psi(\hat y_t\mid\hat y_{<t},Z,q).$$
做下游基因组分类任务时直接丢掉解码器，用冻结的视觉编码器提取特征训练线性探针。

<a id="p-006"></a>
### ⚪ **SPU-DNA**：结合多尺度卷积与时频滤波的 DNA 建模
- **paper**：[**Adaptive DNA Sequence Modeling via Synergistic Plasticity Units**](https://openreview.net/forum?id=coNswqxIlk)

为了在 $\mathcal{O}(L\log L)$ 复杂度下同时捕捉局部 motif、长程调控和周期性信号，**SPU-DNA** 设计了由三部分串联的协同可塑性单元（SPU）：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-glm-052-spu.png)

1. **局部层（LPL）**：对输入特征 $E\in\mathbb{R}^{B\times L\times D}$ 用多个不同核宽的静态卷积提取多尺度特征 $F_i$，再按 $1\times 1$ 卷积生成的位点权重 $m_{j,i}$ 动态聚合感受野：$F_{\mathrm{lpl},j}=\sum_{i}m_{j,i}F_{i,j}$。
2. **时频全局层（DPL）**：分两条并行路径处理 $F_{\mathrm{lpl}}$——**时域路径**由 MLP 生成复数滤波器并乘以指数衰减窗得到长卷积核 $p$，利用快速傅里叶变换（FFT）执行全局长卷积得到 $\hat F_{\mathrm{lpl}}$；**频域路径**对 $F_{\mathrm{lpl}}$ 逐级做小波分解提取低频与高频子带 $(P_i^l, P_i^h)=\mathrm{WT}(P_{i-1}^l)$（$P_0^l=F_{\mathrm{lpl}}$），在各高频子带上做全局滤波得到 $\hat P_i^h$，再以可学习尺度因子 $\gamma_i$ 逐级做逆小波变换（IWT）重构 $\tilde P_i^l=P_i^l+\mathrm{IWT}(\gamma_i\tilde P_{i+1}^l,\hat P_{i+1}^h)$ 并累加回时域：
   $$\hat F_{\mathrm{lpl}}=\mathrm{CenterCrop}_L\!\left(\mathrm{iFFT}\big(\mathrm{FFT}(F_{\mathrm{lpl}})\odot\mathrm{FFT}(p)\big)\right), \quad F_{\mathrm{dpl}}=\hat F_{\mathrm{lpl}}+\mathrm{IWT}(\gamma_0\tilde P_1^l,\hat P_1^h).$$
3. **显著性门控（SPL）**：分别从通道轴（均值池化 + MLP 得到 $S_c$）和位置轴（拼接通道均值与最大值 + 深度可分离卷积得到 $S_p$）计算门控权重，逐元素调制输出 $F_{\mathrm{out}}=F_{\mathrm{dpl}}\odot S_c\odot S_p$。

### ⚪ **BIOARC**：生物基础模型的神经架构搜索
- **paper**：[BIOARC: Discovering Optimal Neural Architectures for Biological Foundation Models](https://openreview.net/forum?id=9yts8LUZiA)

直接照搬 NLP 的纯 Transformer 架构未必适合生物序列。**BIOARC** 在包含 `{CNN, LSTM, Transformer, Mamba, Hyena}` 五类算子的混合搜索空间 $\mathcal A$ 里做权重共享超网神经架构搜索（NAS）。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-021-bioarc.png)

为了缩小搜索空间，先施加隐藏层维度单调递增约束、对数维度距离过滤和 K-Means 质心聚类筛选代表性路径。设超网总参数为 $W$，候选路径 $a\in\mathcal A$ 激活对应的共享参数子集 $w(a)\subseteq W$。预训练采用单路径随机采样（SPOS）：每步均匀抽取一条架构路径 $a$ 在无标注语料 $X$ 上最小化自监督损失 $\mathcal L$ 的期望：
$$\min_W \mathbb E_{a\sim\mathcal A}\Big[\mathcal L\big(\mathcal A(X; w(a))\big)\Big].$$
下游评估时，各候选路径继承超网权重独立微调，按跨任务 Z-score 标准化平均分选出最优架构从头训练。实验发现，DNA 任务搜索出的最优架构收敛为 **“Hyena（首层提取全局背景）$\to$ Transformer（中层定位 TSS 边界）$\to$ CNN（末层识别局部启动子元件）”** 的混合拓扑。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-022-bioarc-exp.png)

## 1.2 训练目标、可解释性与评测

<a id="p-007"></a>
### ⚪ **Gamba**：把跨物种进化速率预测作为基因组预训练任务
- **paper**：[**Predicting evolutionary rate as a pretraining task improves genome language model representations**](https://openreview.net/forum?id=FOIP4Blm4F)

纯碱基重建（MLM/NTP）容易把大量表征容量浪费在非功能背景序列上。**Gamba** 引入单碱基跨物种进化保守性分数（**PhyloP**）作为联合预训练目标，让模型在只输入单条人类 DNA 序列（推理时无需多序列比对 MSA）的条件下学习进化约束。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-006-gamba.png)

模型顶部除了预测 4 种碱基交叉熵 $\mathcal L_{\mathrm{CE}}$，还加了一个进化预测头，将位点 $i$ 的隐状态映射为高斯均值 $\mu_i$ 和方差 $\sigma_i^2$ 以拟合真实 PhyloP 分数 $y_i$，最小化高斯负对数似然（支持单向自回归 CEP 和双向掩码 MEM 两种模式，$\epsilon$ 为方差截断常数）：
$$\mathcal L = \mathcal L_{\mathrm{CE}} + \frac1N\sum_{i=1}^N\left[\frac12\log\max(\sigma_i^2,\epsilon)+\frac{(y_i-\mu_i)^2}{2\max(\sigma_i^2,\epsilon)}\right].$$

<a id="p-008"></a>
### ⚪ **SAE-gLM**：用稀疏自编码器拆解基因组模型的内部特征
- **paper**：[**Interpreting Genomic Language Models using Sparse Autoencoders**](https://openreview.net/forum?id=boBP35BB2U)

基因组大模型的神经元往往具有多义性。**SAE-gLM** 提取预训练模型的中间层单碱基嵌入 $x\in\mathbb R^d$，训练过完备（字典维度 $m\gg d$，激活函数 $\sigma(\cdot)$ 为 BatchTopK）的稀疏自编码器，将其分解为稀疏激活的近单义隐特征：
$$\hat x=W_{\mathrm{dec}}\sigma(W_{\mathrm{enc}}x+b_{\mathrm{enc}})+b_{\mathrm{dec}}.$$

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-007-saeglm.png)

论文用单碱基 Precision 与连续注释区间级 Recall、单变量线性探针、以及点事件（如 TSS）窗口富集比来对齐已知生物学概念；同时提取各隐特征在长序列上的激活轨迹向量 $x_i, x_j\in\mathbb R^L$，计算适合稀疏向量的连续 Tanimoto 相似度 $K_{ij} = \frac{x_i^\top x_j}{\|x_i\|_2^2 + \|x_j\|_2^2 - x_i^\top x_j + \epsilon}$ 构建共激活特征图谱，并通过比较参考与突变序列的特征激活对数比来定位致病变异破坏的调控基序。

<a id="p-009"></a>
### ⚪ **GENEB**：基于冻结探针的基因组基础模型评测基准
- **paper**：[**GENEB: Why Genomic Models Are Hard to Compare**](https://openreview.net/forum?id=uZerXmyozE)

为了公平对比不同架构、分词和语料的基因组模型，**GENEB** 收集了 $K=13$ 个功能类别共 100 个 DNA 分类任务，对 40 个预训练模型执行统一的**冻结编码器 + 均值池化 + 逻辑回归探针**评测，以跨类别的宏平均马修斯相关系数 $\mathrm{MacroMCC}=\frac1K\sum_{k=1}^K\mathrm{MCC}_k$ 作为主指标。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-008-geneb.png)

通过控制单一变量的配对实验，基准得出了三个主要结论：
1. **物种错配比规模更关键**：十亿参数的原核模型在真核剪接任务上垫底，同域内小模型经常反超大模型；
2. **架构与分词高度依赖任务粒度**：受控对比下 Transformer 整体优于所评估的 Mamba（但 Mamba 在染色质可及性上更优）；剪接位点等细粒度任务偏好单碱基分词，甲基化偏好 k-mer；
3. **全量榜单不能直接指导少样本选型**：从全量数据切换到 1-shot / 10-shot 时，过半数任务类别的榜首模型发生更替。

### ⚪ **EDEN**：宏基因组基础模型的缩放律分析
- **paper**：[**Scaling Laws and Architectural Frontiers in Metagenomic Foundation Models**](https://openreview.net/forum?id=JWs8VUevwO)

**EDEN** 在高质量长读长宏基因组语料 **BaseData** 上，以单碱基分辨率对比了全注意力（Llama3）、状态空间混合（Mamba-2-Hybrid）和长卷积混合（Striped Hyena）三类自回归架构在验证损失 $L$ 与算力 $C$（FLOPs）之间的幂律缩放关系 $L(C)\propto C^{-\alpha}$。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-011-eden1.png)

实验发现了两个核心现象：（1）**序列组装连续性决定缩放斜率**：长读长连续组装语料拟合出的幂律指数 $\alpha$ 显著高于碎片化短读长语料（OpenGenome2）；（2）**递归记忆瓶颈 vs. 精确检索**：Mamba 和 Hyena 在长序列外推时能维持平滑的统计特征，但受限于固定维度的递归状态，容易打乱保守操纵子的基因顺序；而全注意力 **Llama** 在罕见基因困惑度、序列补全折叠质量和基因顺序恢复率上全面胜出。作者据此训练了 28B 全注意力模型 **EDEN-28B**。

## 1.3 基因调控网络

<a id="p-016"></a>
### ⚪ **SupGCL**：用真实基因敲低实验指导调控网络图对比学习
- **paper**：[**Supervised Graph Contrastive Learning for Gene Regulatory Networks**](https://openreview.net/forum?id=0Y7itV1kb7)

在基因调控网络（GRN，节点集 $V$）上做图对比学习时，随机删点删边很容易破坏主调控因子的关键拓扑。**SupGCL** 引入真实的基因敲低（knockdown）实验构建的调控图 $H^a$（敲低基因 $a\in\mathcal K$）作为教师网络，指导虚拟敲低增强（将原图中节点 $a$ 及其相连边特征置零）生成的学生网络 $G^a$。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-013-supgcl.png)

用共享权重的 Graph Transformer $f_\phi$ 提取学生和教师的节点表征矩阵 $Z^a=f_\phi(G^a), Y^a=f_\phi(H^a) \in \mathbb{R}^{|V|\times d}$，基于 Frobenius 内积余弦相似度 $\mathrm{sim}_F(\cdot,\cdot)$ 定义增强对 $(a,b)$ 间的教师分布 $p_\phi(b|a) \propto \exp(\mathrm{sim}_F(Y^a,Y^b)/\tau_a)$ 与学生分布 $q_\phi(b|a) \propto \exp(\mathrm{sim}_F(Z^a,Z^b)/\tau_a)$。总损失联合优化教师加权的节点级对比损失 $\mathrm{Loss}_{\mathrm{Node}}^{a,b}$ 与图级增强分布 KL 散度（其中 $U_{\mathcal K}$ 为 $\mathcal K$ 上的均匀分布）：
$$\mathrm{Loss}_{\mathrm{SupGCL}} = \mathbb{E}_{a,b\sim p_\phi(b|a)U_{\mathcal K}(a)}\big[\mathrm{Loss}_{\mathrm{Node}}^{a,b}\big] + \frac{1}{|\mathcal K|}\sum_{a\in\mathcal K}D_{\mathrm{KL}}\big(p_\phi(b|a)\,\|\,q_\phi(b|a)\big).$$

<a id="p-087"></a>
### ⚪ **UGRN**：用虚拟扰动从单细胞基础模型中提取通用调控网络
- **paper**：[**Towards Universal Gene Regulatory Network Inference: Unlocking Generalizable Regulatory Knowledge in Single-cell Foundation Models**](https://openreview.net/forum?id=dilKIGbrZu)

从冻结的单细胞基础模型 $\mathcal M$（如 scGPT，将输入表达向量重构为 $\hat x = \mathcal M(x)$）中提取基因调控关系时，直接把某个基因的真实表达量置零（zero-out）会因为不同基因基线表达量差异巨大而导致跨基因响应不可比。**UGRN** 完全脱离真实观测矩阵，构造人工合成的虚拟表达向量来蒸馏定长的基因对交互特征 $e_{ij}$，再喂给轻量级 MLP 分类器 $s_{ij} = f_\phi(e_{ij})$：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-042-ugrn.png)

1. **虚拟数值扰动（VVP）**：记 $v_{g_i\leftarrow v}$ 为仅将源基因 $g_i$ 设为数值 $v$、其余背景基因全部固定在统一虚拟基线 $v_b$ 的合成输入向量。将 $g_i$ 依次扰动至一组预设强度 $\{v_{p,1},\dots,v_{p,M}\}$，拼接目标基因 $g_j$ 的重构偏移向量：
   $$e_{ij}^{v_p} = \mathcal M\big(v_{g_i\leftarrow v_p}\big)_j - \mathcal M\big(v_{g_i\leftarrow v_b}\big)_j, \quad e_{ij}^{\text{vvp}} = \Big[e_{ij}^{v_{p,1}};\; \dots;\; e_{ij}^{v_{p,M}}\Big].$$
2. **梯度轨迹蒸馏（GDT）**：沿表达动态范围均匀采样一组虚拟基线状态 $\{v_{b,1},\dots,v_{b,T}\}$，直接反向传播求目标基因 $g_j$ 的重构输出关于源基因 $g_i$ 标量输入 $v_i$ 的瞬时偏导数（局部敏感度）：
   $$\nabla_{ij}^{(t)} = \frac{\partial\mathcal M\big(v_{g_i\leftarrow v_{b,t}}\big)_j}{\partial v_i}, \quad e_{ij}^{\text{gdt}} = \Big[\nabla_{ij}^{(1)};\; \dots;\; \nabla_{ij}^{(T)}\Big].$$
最终将两个特征独立训练的 MLP 预测概率取平均，即可对未见基因对做零样本调控推断。

<a id="p-015"></a>
### ⚪ **PerturbODE**：用模块化神经 ODE 同时预测扰动轨迹与基因调控网络
- **paper**：[Interpretable Neural ODEs for Gene Regulatory Network Discovery under Perturbations](https://openreview.net/forum?id=nG9bsQq2N6)

**PerturbODE** 将干预条件 $I_r$（靶基因下标集合）下细胞的 $d$ 维对数基因表达演化 $y^{(r)}(t)\in\mathbb{R}^d$ 建模为一个具有生物物理结构的神经常微分方程（$\circ$ 表示逐元素乘积）：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-013-perturbode.png)

$$\frac{\partial y^{(r)}(t)}{\partial t} = M_r A\sigma\big(\alpha \circ (By^{(r)}(t) - \beta)\big) + \sum_{j\in I_r} s_j\delta_j - Wy^{(r)}(t).$$
方程中各参数直接对应调控机制：矩阵 $B\in\mathbb{R}^{l\times d}$ 将 $d$ 个基因线性投影至 $l$ 个潜在共调控“基因模块”（$\beta, \alpha$ 为模块激活阈值与速率），逐元素 Sigmoid 激活 $\sigma(\cdot)$ 在对数空间等价于描述转录因子浓度—速率关系的 Hill 函数，再由 $A\in\mathbb{R}^{d\times l}$ 映射回下游基因——因此底层的有向因果基因调控网络（GRN）可直接由共享参数导出为低秩分解 $G = A\operatorname{diag}(\alpha)B$；正对角矩阵 $-Wy^{(r)}$ 建模 RNA 降解与稀释；标准基向量 $\delta_j=e_j$、标量 $s_j$ 及对角掩码矩阵 $M_r = I - \sum_{j\in I_r}\operatorname{diag}(\delta_j)$ 则分别刻画完美干预（切断内源父节点调控的 CRISPR 敲除 $s_j=0$ 或强激活 $s_j>0$；非完美偏移干预则取 $M_r=I$）。

由于初始对照细胞群体 $Y^{(0)}$ 与扰动终末观测群体 $Y^{(r)}$ 无单细胞配对，训练时将 $Y^{(0)}$ 经 ODE 积分至时刻 $T$ 得到预测分布 $\hat Y^{(r)}$，最小化两者间的熵正则化 Sinkhorn Wasserstein-2 距离及上游入边矩阵 $B$ 的 $L_1$ 稀疏惩罚：
$$\mathcal L(\theta) = W_2\big(Y^{(r)}, \hat Y^{(r)}\big) + \lambda\|B\|_1.$$

### ⚪ **RNA-FM Transfer**：RNA 基础模型在下游任务中的迁移机制分析
- **paper**：[**Understanding Transfer Learning of RNA Foundation Models on Downstream Tasks**](https://openreview.net/forum?id=26JHfF3tk7)

RNA 基础模型在下游任务的提升究竟是因为“学到了直接可用的通用特征”，还是因为“提供了更好的优化起点”？这篇工作通过追踪微调时的逐层参数欧氏位移 $\|\theta_l^{(t)}-\theta_l^{(0)}\|_2$ 和收敛点的损失曲面平坦度（$\Delta L_{\mathrm{SAM}}$），对比了 One-hot 线性基线、冻结探针、随机初始化训练和全参微调，得出了三个实证结论：

2. **“冻结浅层、只调深层”在 RNA 功能任务上不成立**：在二级结构任务上浅层权重确实保持低位移；但在未对齐的功能和突变预测（DMS）任务上，全参微调会从浅层词嵌入到深层发生**全局参数重写**。![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-015-rnafm-l2.png)
3. **预训练本质上是导向平坦极小值的优化先验**：尽管特征被大面积改写，全参微调依然显著优于从头训练。损失曲面分析证实，适中容量的预训练权重能引导模型收敛到局部敏感度更低、盆地更宽的平坦极小值区域。![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-016-rnafm-loss.png)

## 2.2 RNA 结构表示与设计

<a id="p-018"></a>
### ⚪ **RiboSphere**：RNA 三维结构的离散词元化与流匹配解码
- **paper**：[**RiboSphere: Learning Unified and Efficient Representations of RNA Structures**](https://openreview.net/forum?id=BaHOWWzl5B)

实验解析的 RNA 3D 结构稀缺，连续潜空间自编码器容易过拟合。**RiboSphere** 采用“浅层几何编码器 + 有限标量量化（FSQ） + 深层流匹配解码器”的非对称架构，把连续 3D 结构压缩为离散词元。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-017-ribosphere.png)

编码器注入成对距离与相对位置偏置，通过滑窗注意力提取第 $i$ 个核苷酸的特征 $c_i\in\mathbb R^d$，再用无码本的 FSQ 将每个通道 $k$ 量化为 $L_k$ 个离散水平 $\hat c_{i,k}$（配合直通估计器 STE 传梯度，平移至非负整数后按混合基数展开为离散结构词元序列 $\hat c$）：
$$\hat c_{i,k} = \mathrm{round}\!\left(\lfloor L_k/2\rfloor \tanh(W_k c_i)\right).$$
解码器在零质心高斯先验 $x_0\sim\mathcal N(0,I)$ 与真实三维坐标 $x_1$ 的线性插值路径 $x_t = tx_1 + (1-t)x_0$（$t\in[0,1]$）上，以离散词元 $\hat c$ 为条件训练速度场网络 $v_\phi$：
$$\mathcal L_{\mathrm{flow}} = \mathbb E_{x_0,x_1,t}\Big[\big\|v_\phi(x_t,t,\hat c) - (x_1 - x_0)\big\|_2^2\Big].$$
预训练后冻结编码器，离散结构词元 $\hat c$ 可直接接 GVP 解码器做 RNA 逆折叠，或接三角注意力模块做配体结合预测。

<a id="p-019"></a>
### ⚪ **CocoRNA**：用多智能体强化学习做 RNA 二级结构逆向设计
- **paper**：[**CocoRNA: Collective RNA Design with Cooperative Multi-agent Reinforcement Learning**](https://openreview.net/forum?id=ES14qDqVB4)

给定长度为 $\ell$ 的目标点括号二级结构 $x_t$，RNA 逆向设计的搜索空间随长度指数增长。**CocoRNA** 采用“集中式训练、分散式执行”的多智能体强化学习（MAPPO），按序列位置或按茎环结构元件把序列拆给 $n$ 个智能体协作填碱基。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-018-cocorna.png)

每个智能体只观测半径为 $\kappa$ 的局部窗口状态 $o_t^i = (s_{\mathrm{seq}}^{[i-\kappa,i+\kappa]},\ s_{\mathrm{struct}}^{[i-\kappa,i+\kappa]})$，并在配对位点施加硬掩码，只允许采样满足 Watson-Crick（A-U, G-C）或摆动配对（G-U）的合法碱基。每步调用折叠工具预测当前序列的二级结构 $x_f$，计算其与目标结构 $x_t$ 的汉明距离 $H_t=\sum_{i=1}^\ell\mathbf{1}(x_f^i\neq x_t^i)$；奖励函数在未完全匹配时奖励距离缩减量，完全匹配（$H_t=0$）时激活终局奖励 $C>0$ 及 GC 含量/最小自由能辅助奖励 $r_{\mathrm{aux}}$：
$$R_t = \begin{cases} (H_{t-1}-H_t)/\ell, & \text{if } H_t > 0, \\ C + r_{\mathrm{aux}}, & \text{if } H_t = 0. \end{cases}$$

<a id="p-020"></a>
### ⚪ **ATL-FGD**：结合自适应图裁剪与语言模型蒸馏的 RNA 逆折叠
- **paper**：[**Learning Adaptive Topology with FiLM-Guided Distillation for Tertiary Structure-Based RNA Design**](https://openreview.net/forum?id=68GUslfGLY)

基于 3D 结构的 RNA 逆折叠有两个痛点：固定的 $k$-NN 图容易在边缘引入噪声边或漏掉长程接触，且 3D 结构训练样本稀缺。**ATL-FGD** 从图拓扑和跨模态蒸馏两方面改进 MPNN：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-019-altfgd.png)

1. **自适应拓扑学习（ATL）**：在每层图消息传递中，拼接两端节点隐状态与几何边特征计算边激活概率 $p_{ij}^{(\ell)} = \sigma(f_\theta([h_i^{(\ell)}, h_j^{(\ell)}, e_{ij}]))$，用直通估计器（STE）采样二值门控动态裁剪噪声边连接。
2. **FiLM 跨模态蒸馏（FGD）**：训练时引入大规模 RNA 语言模型作为教师。为避免直接逐点对齐不同感受野的教师特征 $h_{\mathrm{tea}}$ 与学生 GNN 末层特征 $h_{\mathrm{stu}}$ 引发退化，分别用两个独立的 FiLM 线性调制头生成逐通道缩放与平移参数 $(\gamma_{\mathrm{tea}}, \beta_{\mathrm{tea}}) = g_{\mathrm{tea}}(h_{\mathrm{tea}})$ 和 $(\gamma_{\mathrm{stu}}, \beta_{\mathrm{stu}}) = g_{\mathrm{stu}}(h_{\mathrm{stu}})$，用 $\gamma_{\mathrm{stu}}\odot h_{\mathrm{stu}} + \beta_{\mathrm{stu}}$ 预测碱基 $y_i$，并在调制参数空间做 MSE 蒸馏（推理时移除教师分支）：
   $$\mathcal L_{\mathrm{total}} = -\sum_{i=1}^L \log P\big(y_i = y_i^{\mathrm{true}}\big) + \alpha\Big(\|\gamma_{\mathrm{stu}}-\gamma_{\mathrm{tea}}\|_2^2 + \|\beta_{\mathrm{stu}}-\beta_{\mathrm{tea}}\|_2^2\Big).$$

## 3.1 蛋白质表示与标记化

<a id="p-024"></a>
### ⚪ **ProtDiS**：用生物物理先验解耦蛋白质微环境表征
- **paper**：[**Learning Protein Structure-Function Relationships through Knowledge-guided Representation Decomposition**](https://openreview.net/forum?id=OM0C7jyV0p)

ESM-3 等模型的残基微环境表征把几何、理化和拓扑信号纠缠在单一向量里，遇到结构高度相似但功能分化的蛋白质（同折异功酶）时容易混淆。**ProtDiS** 基于信息瓶颈原理，把冻结的残基微环境嵌入 $s\in\mathbb R^{128}$ 分解为 $K=8$ 个显式物理化学通道 $\{Z_1,\dots,Z_8\}$（分别受从原子坐标直接算出的二级结构、溶剂可及性、B-因子、接触数、疏水性、氢键能、接触熵和局部曲率标签 $Y_k$ 监督）和 1 个互补残差通道 $Z_c$：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-062-protdis.png)

$$\min_{Z_k}\; I(Z_k; s) - \beta_k I(Z_k; Y_k) \;\; (k=1,\dots,8), \qquad \max_{Z_c}\; I(Z_c; s) - \gamma\sum_{k=1}^8 I(Z_c; Y_k).$$
端到端训练时联合优化五项损失：各物理属性的监督预测损失 $\mathcal L_{\text{sup}}$、批级高斯 KL 容量瓶颈、消除批标准化通道 $\tilde Z_i, \tilde Z_j\in\mathbb R^{N\times D}$ 间二阶相关性的互协方差惩罚 $\left\|\frac1N\tilde Z_i^\top\tilde Z_j\right\|_F^2$、残差通道重构损失 $\mathcal L_{\text{rec}} = \|r(Z_c) - s\|_1$，以及在残差通道上加梯度反转层（GRL）防止泄露已知物理属性的对抗分类损失 $\mathcal L_{\text{adv}}$。下游任务通过探针筛选前 4~5 个最相关的通道门控融合，显著提升了跨折叠泛化能力。

<a id="p-026"></a>
### ⚪ **SLAE**：基于局部全原子环境与物理能量约束的蛋白质自编码器
- **paper**：[**SLAE: Strictly Local All-atom Environment for Protein Representation**](https://openreview.net/forum?id=4HDRkXxqNs)

现有的结构分词器大多只看主链，忽略了侧链原子细节。**SLAE** 采用“严格局部编码—全局解码”的非对称架构：编码器不引入任何序列索引或氨基酸类型，只在 $8\,\text{\AA}$ 截断半径内构建重原子图，用 $SE(3)$ 等变张量积更新特征并经“边$\to$原子$\to$残基”两级池化压缩为 128 维的残基局部不变表征 $z_r$。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-063-slae.png)

全局自注意力解码器接收整条链的 $\{z_1,\dots,z_n\}$，通过三个并行预测头迫使局部表征记住全原子物理化学线索：（1）全原子 3D 坐标重构（全原子平滑局部距离差测试损失 $\mathcal L_{\text{sLDDT}}$ + 全原子标架对齐点误差 $\mathcal L_{\text{FAPE}}$）；（2）20 类氨基酸序列恢复交叉熵 $\mathrm{CrossEntropy}(s, \hat s)$；（3）成对残基间的 Rosetta 物理能量项 $r\in\mathbb R^{n\times n\times 3}$（氢键能、溶剂化能、库仑静电势）回归：
$$\mathcal L = w_{\text{coord}}\big(\alpha\mathcal L_{\text{sLDDT}} + \beta\mathcal L_{\text{FAPE}}\big) + w_{\text{seq}}\mathrm{CrossEntropy}(s, \hat s) + w_{\text{energy}}\|r - \hat r\|_2^2.$$
无需显式 KL 先验正则，在学到的平滑潜空间对两个实验构象态做简单线性插值，即可解码出符合分子动力学模拟的全原子构象转变轨迹。

<a id="p-058"></a>
### ⚪ **TEDBench & MiAE**：大规模蛋白质折叠分类基准与高掩码自编码器
- **paper**：[**Protein Fold Classification at Scale: Benchmarking and Pretraining**](https://openreview.net/forum?id=jPKqiaPTEd)

这篇工作做了两件事：首先整合 TED 结构域注释与 AlphaFold 数据库，构建了包含 46 万个结构、覆盖 965 个 CATH 拓扑类别的非冗余折叠分类基准 **TEDBench**（比旧基准扩大 30 倍）。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-064-tedbench.png)

其次，针对蛋白质相邻残基几何高度冗余（低掩码率下模型靠局部插值就能作弊）的问题，提出了掩码不变自编码器 **MiAE**。模型将每个残基表示为由主链 $(\mathrm N, \mathrm C_\alpha, \mathrm C)$ 构造的局部刚体标架 $T_i = (R_i, t_i) \in SE(3)$，预训练时**均匀随机掩码高达 90% 的残基标架**，重型编码器完全丢弃掩码位点，只在剩下的 10% 稀疏可见标架上跑全局 $SE(3)$ 不变几何自注意力和 Transformer；再拼上可学习掩码词元，由极轻量的 RoPE Transformer 解码器在全部残基上重构主链成对距离与方向回归损失（$\mathcal L_{\text{dist}} + \mathcal L_{\text{dir}}$）、分箱距离与方向分类损失（$\mathcal L_{\text{binned\_dist}} + \mathcal L_{\text{binned\_dir}}$）以及逆折叠序列交叉熵（$\mathcal L_{\text{inverse\_folding}}$）：
$$\mathcal L_{\text{ESM3}} = \mathcal L_{\text{dist}} + \mathcal L_{\text{dir}} + \mathcal L_{\text{binned\_dist}} + \mathcal L_{\text{binned\_dir}} + \mathcal L_{\text{inverse\_folding}}.$$
借此将预训练开销压缩到仅需 768 GPU 小时（比 ESM2/SaProt 减少两个数量级），并在 TEDBench 上取得最优分类性能。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-065-miae.png)

<a id="p-022"></a>
### ⚪ **APT**：由粗到细的全局自适应蛋白质结构词元化
- **paper**：[**Adaptive Protein Tokenization**](https://openreview.net/forum?id=UG06mAANLH)

现有的蛋白质结构分词器是“逐残基局部对应”的，不仅词元数绑定残基长度 $L$，而且自回归生成时错一个词元就会导致后续结构崩溃。**APT** 模仿傅里叶展开，把词元序列改造成**从粗到细的全局描述符**：前缀词元编码全局低频折叠拓扑，尾部词元递进补充高频局部细节（第 1 个词元还专门负责预测蛋白质总长度分类损失 $\mathcal L_{\text{size}}$，实现残基长度与词元数解耦）。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-066-apt.png)

训练时，双向 Transformer 编码器 + FSQ 将干净 $\mathrm C_\alpha$ 坐标 $x_1\in\mathbb R^{L\times 3}$ 量化为离散词元序列 $\hat c$，并施加**嵌套随机失活（Nested Dropout）**——每次随机采样截断位置 $k$，只保留前缀 $\hat c_{1:k}$ 作为条件送入流匹配扩散解码器 $v_\theta$，在加噪坐标 $x_t = t x_1 + (1-t)\epsilon$（$\epsilon\sim\mathcal N(0,I)$）上优化流匹配损失：
$$\mathcal L = \big\|(x_1 - \epsilon) - v_\theta(x_t, t, \hat c_{1:k})\big\|_2^2 + \lambda_{\text{size}}\mathcal L_{\text{size}}.$$
在自回归生成蛋白质词元时，可以根据预测分布的香农熵在尾部高噪处直接截断，并在扩散解码积分后期采用**分类器退火**（$\alpha\in[0,1]$，随 $t\to 1$ 从条件流平滑退火至无条件流 $v_\theta^{\text{anneal}}(x_t, t) = v_\theta(x_t, t\mid\varnothing) + (1 - t^\alpha)(v_\theta(x_t, t\mid\hat c) - v_\theta(x_t, t\mid\varnothing))$）将局部几何约束回天然物理流形。由于任意前缀都代表完整蛋白质，APT 原生支持改小解码目标长度实现“零样本蛋白质缩小”，以及在词元前缀上直接执行测试期束搜索（Beam Search）。

## 3.2 蛋白质语言模型

<a id="p-023"></a>
### ⚪ **PRISM**：显式区分种系残基与体细胞突变的抗体语言模型
- **paper**：[**Explicit representation of germline and non-germline residues improves antibody language modeling**](https://openreview.net/forum?id=INxIx5piFC)

天然抗体序列 90% 以上与种系（Germline, GL）模板一致，导致常规抗体语言模型存在严重的“种系偏置”，把决定抗原高亲和力的罕见体细胞高频突变（Non-Germline, NGL）当成统计噪声压低概率。**PRISM** 把词表扩充为区分大小写的 $|V_{\text{ext}}|=53$ 个词元（大写代表 GL，小写代表 NGL），将词元建模拆解为因子化推断 $P(\text{token}) = P(\text{origin})\times P(\text{aa}\mid\text{origin})$。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-067-prism.png)

对于目标词元 $y\in V_{\text{ext}}$，记其基础氨基酸身份为 $\mathcal M(y)$、进化起源类别为 $\mathcal Z(y)\in\{\text{GL}, \text{NGL}\}$。模型在位点 $i$ 隐状态 $h_i$ 上设置起源分类头 $P_{\text{orig}}$、氨基酸对数概率头 $l_i^{\text{aa}}$（中间用停止梯度算子阻断氨基酸误差向起源头回传）和位置门控 $\alpha_i\in[0,1]$，在对数空间合成最终得分（在高频突变的 CDR 环处 $\alpha_i\to 1$ 充分注入起源先验，在保守结构锚点处 $\alpha_i\to 0$）：
$$s_{i, y} = l_{i, [\mathcal M(y)]}^{\text{aa}} + \alpha_i\cdot\log P_{\text{orig}}\big(\mathcal Z(y)\mid h_i\big), \qquad P(y_i = k) = \frac{\exp(s_{i, k}/T)}{\sum_{j\in V_{\text{ext}}}\exp(s_{i, j}/T)}.$$
推理端无需任何微调：只累加突变位点小写 NGL 词元的掩码对数似然即可做零样本抗原结合亲和力正向打分；而在重采样时指定只从大写或小写词元采样，即可分别定向优化抗体结构稳定性或界面结合能。

<a id="p-025"></a>
### ⚪ **ProtoMech**：用跨层转码器追踪和干预蛋白质语言模型的计算电路
- **paper**：[**Protein Circuit Tracing via Cross-layer Transcoders**](https://openreview.net/forum?id=Ki0eWT1sFS)

逐层独立训练的稀疏自编码器（SAE）很难追踪跨越多层的上下文累积。**ProtoMech** 引入跨层转码器（Cross-layer Transcoders, CLT）：冻结 ESM-2 的注意力层，将第 $\ell$ 层进入 MLP 前的残差流激活 $x^\ell$ 经编码器与 $\mathrm{TopK}$ 算子映射为稀疏潜向量 $a^\ell = \mathrm{TopK}(W_{\text{enc}}^\ell(x^\ell - b_{\text{pre}}^\ell) + b_{\text{enc}}^\ell)$，并通过跨层解码器矩阵组累加**从第 1 层至第 $\ell$ 层的所有稀疏潜特征**来重构当前层 MLP 的原始输出 $y^\ell = \mathrm{MLP}^\ell(x^\ell)$：
$$\hat y^\ell = \sum_{\ell'=1}^\ell W_{\text{dec}}^{\ell'\to\ell} a^{\ell'} + b_{\text{pre}}^\ell, \qquad \mathcal L_{\text{CLT}} = \sum_{\ell=1}^L \big\|y^\ell - \hat y^\ell\big\|_2^2 + \alpha\sum_{\ell=1}^L \big\|e^\ell - \hat e^\ell\big\|_2^2,$$
其中第二项为利用同层解码器重构残差 $e^\ell = y^\ell - \hat y^\ell$ 以防止死神经元的辅助损失。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-068-protomech.png)

基于训练好的 CLT 替代模型，计算各稀疏节点 $a_i^\ell$ 对下游探针预测目标 $y$（家族分类或 DMS 适应度）的一阶梯度归因 $\Delta_i^\ell = \left|a_i^\ell\cdot\frac{\partial y}{\partial a_i^\ell}\right|$，仅需贪心挑出不到 1% 的节点即可恢复完整电路性能，清晰呈现出“浅层单氨基酸识别 $\to$ 深层催化基序/疏水核心组装”的跨层计算图。推理时将电路内高归因节点的激活值钳制（clamp）放大并加上野生型重构残差校正，即可直接操控解码出高适应度的蛋白质突变体。

<a id="p-027"></a>
### ⚪ **PLMs-Repeats-Circuits**：解析蛋白质语言模型检测序列重复的内部电路
- **paper**：[**Induction Meets Biology: Mechanisms of Repeat Detection in Protein Language Models**](https://openreview.net/forum?id=vPUInIYURl)

蛋白质中常包含串联重复片段（含进化点突变的近似重复），ESM-3 和 ESM-C 能通过掩码预测精准补全其中的残基。这篇工作将未掩码重复段中的氨基酸替换为 BLOSUM62 最高分替换残基以构造反事实序列 $\hat s$，利用积分梯度归因修补（AP-IG）量化候选电路 $c$ 恢复正确氨基酸对数概率 $L_a$ 的忠实度 $F(c) = \frac{L_a(s\to\hat s) - L_a(\hat s)}{L_a(s) - L_a(\hat s)}$，逆向定位了模型内部的重复检测电路（仅占每层 3%~7% 的神经元）。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-069-induction.png)

分析表明，近似重复电路在结构与功能上完全包含并泛化了精确重复电路，其三阶段协同计算路径为：
1. **浅层上下文对齐**：相对位置注意力头与编码 **BLOSUM62 进化可替换氨基酸团**（如 $\{I, V\}$、$\{D, E, N\}$）及理化性质的浅层 MLP 神经元协同，跨越单点突变建立两段重复片段的对齐表征；
2. **中层跨片段归纳复制**：中层的**归纳注意力头（Induction Heads）**利用已对齐表征，从掩码位点精准跨距关注另一重复段中的对应对齐词元，将其身份复制写入残差流；
3. **深层分布精炼**：深层单氨基酸特异神经元和氨基酸偏置注意力头共同重塑并锐化最终词表输出分布。

## 3.3 蛋白质结构生成

<a id="p-032"></a>
### ⚪ **PAR**：基于“下一尺度预测”的蛋白质主链多尺度自回归生成
- **paper**：[**Protein Autoregressive Modeling via Multiscale Structure Generation**](https://openreview.net/forum?id=08tW615mgI)

按残基从左到右自回归生成蛋白质 3D 结构既慢又违背远端残基间的双向空间耦合。**PAR** 将自回归范式改造为**“下一尺度预测（Next-Scale Prediction）”**：通过沿序列维度的无参线性插值下采样算子 $\mathrm{Down}(\cdot)$，把长度为 $L$ 的主链 $\mathrm C_\alpha$ 坐标序列 $x\in\mathbb R^{L\times 3}$ 拆成由粗到细的 $n$ 个尺度 $X = \{x^1, x^2, \dots, x^n\}$（如长度 $\mathrm{size}(i) \in \{64, 128, 256\}$，$x^n=x$），在尺度间做自回归，而在每个尺度内部保留全双向空间依赖：
$$p_\theta(x) = \prod_{i=1}^n p_\theta\big(x^i \mid X_{<i}\big) = \prod_{i=1}^n p_\theta\Big(x^i \;\Big|\; z^i = \mathcal T_\theta(X_{<i})\Big).$$

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-070-par.png)

在第 $i$ 个尺度上，自回归 Transformer $\mathcal T_\theta$ 接收线性上采样后的前序粗尺度结构序列并输出条件嵌入 $z^i$；随后，跨尺度共享的连续流匹配解码器 $v_\theta$ 在高斯噪声 $\epsilon^i\sim\mathcal N(0,I)$ 与真实坐标 $x^i$ 的线性插值 $x_{t^i}^i = t^i x^i + (1-t^i)\epsilon^i$（$t^i\in[0,1]$）上直接回归速度场：
$$\mathcal L(\theta) = \mathbb E_{x}\left[\frac1n\sum_{i=1}^n\frac{1}{\mathrm{size}(i)}\mathbb E_{t^i, \epsilon^i}\Big\|v_\theta\big(x_{t^i}^i, t^i, z^i\big) - \big(x^i - \epsilon^i\big)\Big\|_2^2\right].$$
训练时通过给前序粗尺度上下文加噪（NCL）和用模型自身单步预测替换真实上下文的计划采样（Scheduled Sampling）消除暴露偏差；推理时只在序列最短的第 1 级粗尺度跑 400 步 SDE 确立全局拓扑，后续精细尺度只跑 2 步 ODE 快速精炼，在保持 95%+ 可设计性的同时实现 $2.5\times$ 采样加速。

### ⚪ **BioDynaSpec**：在频域做自回归扩散，生成长程蛋白质动力学轨迹
- **paper**：[**BioDynaSpec: Harmonic-Guided Spatio-Spectral Autoregressive Diffusion for Protein Dynamics Generation**](https://openreview.net/forum?id=TwMRZPkn4e)

在时域逐帧生成分子动力学（MD）轨迹容易把低频集体构象重排和高频局部热振动混在一起，导致长程外推漂移。**BioDynaSpec** 从近平衡简正模物理出发，将 $N_r$ 个残基的轨迹切分为长度为 $W$ 的无重叠窗口，在窗口内通过 Kabsch 算法对齐到首帧锚点构象 $x_{\text{start}}^{(k)}$ 后，沿时间轴做实数快速傅里叶变换（rFFT），把时域轨迹转化为按频率分箱 $f\in\{0,\dots,F-1\}$（$F=\lfloor W/2\rfloor+1$）排列的频谱词元 $X_{\text{tok}}^{(k)}\in\mathbb R^{N_r\times F\times 6}$（拼接归一化复系数的三维实部与虚部）。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-071-biodynaspec.png)

在编码窗口首帧锚点结构时，受分子谐波势 $\propto d_{ij}^2$ 启发，在多头空间注意力中引入基于锚点残基间欧氏距离 $d_{ij}$ 与可学习头特异刚度系数 $\tau_h = \mathrm{softplus}(\gamma_h)\ge 0$ 的**残基间频率耦合（IRFC）**偏置（大 $\tau_h$ 聚焦局部刚性高频振动，小 $\tau_h$ 捕获长程低频集体模，其中 $b_{ij}^{\text{pair}}$ 为成对特征偏置）：
$$\alpha_{ij}^{(h)} = \mathrm{softmax}_j\!\left(\frac{q_i^{(h)\top}k_j^{(h)}}{\sqrt d} + b_{ij}^{\text{pair}} - \tau_h d_{ij}^2\right).$$
随后，时空—频谱混合规划器按**从低频到高频（$f:0\to F-1$）**的物理层次自回归生成条件特征 $c$，驱动扩散 MLP 头 $F_\theta$ 对加噪连续频谱词元 $x_\sigma = x_0 + \sigma\epsilon$ 去噪（$\mathcal L_{\text{diff}} = \mathbb E[\lambda(\sigma)\|F_\theta(x_\sigma; \sigma, c) - x_0\|_2^2]$），最后经逆傅里叶变换（irFFT）还原出时域轨迹并将末帧更新为下一窗口的锚点。

### ⚪ **CalPro**：蛋白质结构预测的共形不确定性校准
- **paper**：[**CalPro: Prior-Aware Evidential Conformal Prediction with Structure-Aware Sensitivity Bounds for Protein Structures**](https://openreview.net/forum?id=3LRWjJTp0Y)

AlphaFold 的 pLDDT 未经严格概率校准，在跨实验模态（如从 X-ray 迁移到 cryo-EM）或固有无序区（IDR）时覆盖率会大幅下降。**CalPro** 在任意冻结的结构预测器外加装一个轻量级事后 3 层 GNN 几何证据头（推理开销仅为基础模型的 $1.2\times$），拟合最优叠合后的逐残基 $\mathrm C_\alpha$ 距离误差 $y_i = \|r_i^{\text{pred}} - r_i^{\text{exp}}\|_2$：单次前向传播输出正态逆伽马（NIG）分布参数 $(\mu_i, \alpha_i, \beta_i, \nu_i)$，导出预测均值 $\mu_i$、方差 $\sigma_i^2 = \frac{\beta_i}{\nu_i(\alpha_i-1)}$ 和尺度自适应非一致性得分 $s_i = \frac{|y_i - \mu_i|}{\sigma_i + \varepsilon}$。

训练时除了 NIG 负对数似然，还结合无序度与预测柔性先验特征 $b(x_i)$ 及单调网络 $m(\cdot)$ 施加单调软约束 $\mathcal L_{\text{prior}} = \lambda\sum_i\max(0, m(b(x_i)) - u(x_i))$，强制高无序区具有更大的认知不确定性 $u(x_i)$。测试期在包含 $N_{\text{prot}}$ 个独立留出蛋白质的校准集上计算蛋白级平均得分的 $\lceil(N_{\text{prot}}+1)(1-\alpha)\rceil$ 经验分位数 $\hat q_{1-\alpha}$，输出具有有限样本边缘覆盖率保证的预测区间：
$$C_{1-\alpha}(x) = \Big[\max\big\{0,\, \mu(x) - \hat q_{1-\alpha}\big(\sigma(x) + \varepsilon\big)\big\},\; \mu(x) + \hat q_{1-\alpha}\big(\sigma(x) + \varepsilon\big)\Big].$$
理论层面，当测试分布 $\mathcal D_1$ 位于校准分布 $\mathcal D_0$ 半径为 $\epsilon$ 的 Wasserstein-1 球内时，设非一致性得分函数的局部 Lipschitz 常数为 $L_s$、得分密度上界为 $M_s$，基于 PAC-Bayesian 理论（后验 $\rho$，先验 $\Pi$）证明最坏情况覆盖率下界满足：
$$\mathbb E_{\psi\sim\rho}\!\left[\Pr_{z\sim\mathcal D_1}\!\big(y\in C_\tau(x)\big)\right] \ge 1 - \alpha - \sqrt{\frac{\mathrm{KL}(\rho\,\|\,\Pi) + \log\frac2\delta}{2 n_{\text{cal}}}} - M_s L_s\epsilon,$$
而 GNN 邻域平滑与先验尺度分离恰好显著压低了 $L_s$ 与 $M_s$，从而收紧了分布偏移退化项 $M_s L_s\epsilon$。

## 3.4 蛋白质设计

<a id="p-043"></a>
### ⚪ **DPLM-Evo**：支持插入与缺失的可变长蛋白质进化离散扩散模型
- **paper**：[**Towards A Generative Protein Evolution Machine with DPLM-Evo**](https://openreview.net/forum?id=hcFVDmmb0J)

传统离散扩散模型序列长度固定，无法模拟自然进化中的插入（Insertion）和缺失（Deletion）。**DPLM-Evo** 通过解耦两个空间解决了这个问题：长度为 $L$ 的**观测序列空间 $\mathcal X = \mathcal V^L$**（词表 $\mathcal V = \mathcal A\cup\{m\}$，$\mathcal A$ 为 20 种氨基酸，$m$ 为掩码）与插入了空位槽词元 $\phi$、长度上采样为 $N=2L$ 的**潜对齐空间 $\mathcal Z = (\mathcal V\cup\{\phi\})^N$**。定义坍缩映射 $\Gamma^{-1}(z) = [z^{(j)} \mid z^{(j)}\neq\phi]$ 将潜序列还原为无空位观测序列，潜空间里 $\phi$ 与氨基酸的互换即自然对应观测空间的插入与缺失。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-072-dplm-evo.png)

前向加噪在潜空间按转移矩阵 $Q_{\text{noise}}$ 执行（包含缺失率 $\omega_{\text{del}}$、插入率 $\omega_{\text{ins}}$、掩码比例 $\rho_{\text{mask}}$ 及氨基酸替换核 $T_{\text{sub}}$，其中 $T_{\text{sub}}$ 由模型自身在掩码上下文下的预测分布动态构造）。神经网络主干直接作用于坍缩后的紧凑观测序列 $x_t = \Gamma^{-1}(z_t)$：记观测序列第 $k$ 个词元在潜序列 $z_t$ 中对应的非 $\phi$ 下标为 $\mathcal I(k)$，并记目标潜序列 $z_0$ 在区间 $(\mathcal I(k), \mathcal I(k+1))$ 内的首个非 $\phi$ 词元为 $v_{\text{next}}^{(k)}$（无插入则为 $\varnothing$）。输出端通过三个独立预测头——氨基酸替换头 $p_\theta^{\text{sub}}$（交叉熵 CE）、缺失二分类头 $p_\theta^{\text{del}}$（二元交叉熵 BCE，预测当前位点在 $z_0$ 中是否变为空位 $\phi$）与插入二分类头 $p_\theta^{\text{ins}}$（预测右侧空槽是否有新残基插入）联合优化分解损失：
$$\begin{aligned}
&\mathcal L_{\text{sub}}^{(k)} = \mathbb I_{\big(z_0^{(\mathcal I(k))}\in\mathcal V \wedge z_t^{(\mathcal I(k))}\in\mathcal V \wedge z_0^{(\mathcal I(k))}\neq z_t^{(\mathcal I(k))}\big)}\cdot\mathrm{CE}\Big(z_0^{(\mathcal I(k))},\, p_\theta^{\text{sub}}(\cdot\mid x_t)\Big),\\
&\mathcal L_{\text{del}}^{(k)} = \mathrm{BCE}\Big(\mathbb I_{\big(z_0^{(\mathcal I(k))}=\phi\big)},\, p_\theta^{\text{del}}(\cdot\mid x_t)\Big), \qquad \mathcal L_{\text{ins}}^{(k)} = \mathrm{BCE}\Big(\mathbb I_{\big(v_{\text{next}}^{(k)}\neq\varnothing\big)},\, p_\theta^{\text{ins}}(\cdot\mid x_t)\Big),\\
&\mathcal L_t = \mathbb E_{x_0, z_0, z_t}\!\left[\sum_{k=1}^{|\Gamma^{-1}(z_t)|}\lambda_{t-1}\Big(\gamma_{\text{sub}}\mathcal L_{\text{sub}}^{(k)} + \gamma_{\text{del}}\mathcal L_{\text{del}}^{(k)} + \gamma_{\text{ins}}\mathcal L_{\text{ins}}^{(k)}\Big)\right].
\end{aligned}$$
推理时可在每步动态删减或插入掩码槽位（如可变长基序支架设计）；做零样本突变与 Indel 评分时，无需逐位掩码重算，直接输入完整野生型序列即可同时读取替换对数几率比与缺失/插入头的对数几率得分。

### ⚪ **LineageFlow**：从祖先序列出发的蛋白质狄利克雷流匹配生成
- **paper**：[**LineageFlow: Flow Matching for High-Fidelity Family-Aware Protein Sequence Generation**](https://openreview.net/forum?id=u0LjAArXHi)

从均匀单纯形噪声或全掩码状态开始生成特定家族的蛋白质，去噪器在早期高噪阶段很难凭空重建保守的催化与结构骨架残基。**LineageFlow** 将家族条件生成重构为**“从共同祖先向现存序列演化”**：先用系统发育工具（IQ-TREE + PAML）推断目标同源家族 $h$ 系统发育树根节点在各位点 $l$ 的边缘祖先氨基酸后验 $p_{\text{root}}^{(h,l)}$，映射为浓度参数 $\alpha_a^{(h,l)} = \varepsilon + \lambda p_{\text{root}}^{(h,l)}(a)$，直接构建 $K=20$ 维概率单纯形上的乘积狄利克雷祖先先验 $q_0^{(h)}(X) = \prod_{l}\mathrm{Dir}(x^{(l)}; \alpha^{(h,l)})$。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-073-lineageflow.png)

对于目标序列的独热顶点 $x_1^{(l)} = e_i$ 与时间尺度 $t_{\max}$，定义沿谱系演化的条件概率路径 $p_t^{(h,l)}(x\mid e_i) = \mathrm{Dir}(x; \alpha^{(h,l)} + (t_{\max}t)e_i)$（$t\in[0,1]$），其满足连续性方程的解析径向条件向量场为 $u_t^{(h,l)}(x\mid e_i) = c_h^{(l)}(x_i, t)(e_i - x)$（其中 $c_h^{(l)}$ 由不完全 Beta 函数导数确定性给出）。训练去噪分类器 $\hat p_\theta(X_1\mid X_t, t)$ 最小化非空位有效位点集 $\mathcal V(X_1)$ 上的交叉熵损失，并合成边缘传输漂移场 $\hat v^{(h,l)}$：
$$\mathcal L(\theta) = \mathbb E_{h, X_1, t, X_t}\!\left[-\frac{1}{|\mathcal V(X_1)|}\sum_{l\in\mathcal V(X_1)}\log\hat p_\theta\big(x_1^{(l)} \mid X_t, t\big)\right], \qquad \hat v^{(h,l)}(X, t; \theta) = \sum_{i=1}^K c_h^{(l)}(x_i, t)\big(e_i - x^{(l)}\big)\hat p_\theta\big(x_1^{(l)} = e_i \mid X, t\big).$$
推理到中间时刻 $t_{\text{int}} = 0.5$ 时，无需向去噪器输入标签或逐时间步求预测器梯度，直接插入单步“定向进化重路由（Rerouting）”——在祖先先验高熵可变位点采样狄利克雷突变，并按外部适应度评分 $J(X)$ 的玻尔兹曼权重 $\propto \exp(\beta J(X))$ 重采样扩增粒子群，即可逼近 KL 正则化最优选择分布 $q_\beta(X) \propto \exp(\beta J(X))p_{\text{mut}}(X)$，在不破坏家族流形的前提下提升折叠置信度与稳定性。

### ⚪ **MOMST**：利用正负样本记忆库做扩散模型测试期多目标蛋白质设计
- **paper**：[**Multi-Objective Protein Design via Memory-Aware Test-Time Scaling in Diffusion Models**](https://openreview.net/forum?id=CG4TVesbcR)

用免训练测试期引导（Test-Time Scaling）做多目标蛋白质设计时，无记忆采样会重复产生相似的结构错误，而简单线性加权求和又会导致弱势指标崩溃。**MOMST** 在测试期维护一个动态更新的**双层外部记忆库 $\mathcal M$**（50% 容量作为精英保留层存历史最高分序列，50% 作为滑动窗口存近期探索样本）。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-074-momst.png)

给定 $D$ 个目标奖励函数，在第 $d$ 个目标上将记忆库按中位数划分为高分正样本集 $\mathcal M_{\text{high}}$ 与低分失败集 $\mathcal M_{\text{low}}$。记序列 $s$ 在位点 $i$ 的氨基酸独热向量为 $a_{i,s}\in\{0,1\}^{20}$、重缩放奖励为 $\tilde r_d(s)$，分别统计正负经验氨基酸偏好分布 $p_d^{\text{pos}}, p_d^{\text{neg}}$，并以两者的加权对数几率比 $s_{\mathcal M}$ 作为自对比信号指数倾斜调制预训练掩码扩散先验 $p_{\text{pre}}$（理论证明当 $|\mathcal M|\to\infty$ 时消去了基础先验并收敛至软最优策略）：
$$\begin{aligned}
&p_d^{\text{pos}}(a_i \mid x_t, \mathcal M) = \frac{\sum_{s\in\mathcal M_{\text{high}}} \tilde r_d(s)\cdot a_{i,s}}{\sum_{s\in\mathcal M_{\text{high}}} \tilde r_d(s) + \epsilon}, \qquad p_d^{\text{neg}}(a_i \mid x_t, \mathcal M) = \frac{\sum_{s\in\mathcal M_{\text{low}}} \tilde r_d(s)\cdot a_{i,s}}{\sum_{s\in\mathcal M_{\text{low}}} \tilde r_d(s) + \epsilon},\\
&s_{\mathcal M}(a_i \mid x_t, \mathcal M) = \sum_{d=1}^D w_d\cdot\Big(\log p_d^{\text{pos}}(a_i \mid x_t, \mathcal M) - \log p_d^{\text{neg}}(a_i \mid x_t, \mathcal M)\Big), \qquad p_{\mathcal M}(a_i \mid x_t) \propto p_{\text{pre}}(a_i \mid x_t)\cdot e^{\lambda\cdot s_{\mathcal M}(a_i\mid x_t, \mathcal M)}.
\end{aligned}$$
每轮去噪轨迹结束后，将当前批次的帕累托非支配前沿样本与历史 Top-$K$ 精英合并为候选池 $s_{\text{pool}}$，计算每个样本在所有 $D$ 个目标上的**最低秩次归一化得分** $r_{\text{pareto}}(s_{\text{pool}, b}) = \min_{d\in\{1,\dots,D\}}\mathrm{RankNormalize}(\tilde r_{\text{pool}, b, d})$，按玻尔兹曼权重 $\propto \exp(r_{\text{pareto}}/\alpha)$ 重采样下一轮进化种子（优先补齐短板指标）。

### ⚪ **IDEAS**：用特征归因指导基序替换的生物序列定向进化
- **paper**：[**Interpretability Driven Evolutionary Approach for the Design of Biological Sequences**](https://openreview.net/forum?id=gaq60U4jvU)

在实验评估预算受限的主动学习序列设计中，随机突变搜索效率低。**IDEAS** 用可解释性特征归因来引导定向进化：每轮在当前累积数据集上训练可解释代理预测模型 $\hat y_i = g(x_i;\theta)$，提取 Top-$B$ 精英序列 $x_i\in V^L$ 在各个位点对目标属性的正向归因向量 $\phi_i\in\mathbb R^L$。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-020-ideas.png)

用长度为 $m$ 的滑窗扫描精英序列，计算连续子序列 $s_j\in V^m$ 的窗口平均归因得分 $I_j = \frac1m\sum_{k=j}^{j+m-1}\phi_i[k]$，去重归并后构建大小为 $n_m$ 的高分候选功能基序库 $M=\{(s_s, I_s)\}_{s=0}^{n_m-1}$。在突变精英序列 $x_i$ 时，先求其各起始位置 $j$ 的局部窗口归因和 $\psi_i[j] = \sum_{k=j}^{j+m-1}\phi_i[k]$，再按温度 $\tau_1, \tau_2$ 构造采样分布——倾向于选中序列里**归因贡献最低的非关键区域**（低 $\psi_i[j]$），并用基序库里**正向贡献最高的功能基序**（高 $I_s$）替换：
$$p_i[j] = \frac{\exp(-\psi_i[j]/\tau_1)}{\sum_{k=0}^{L-m}\exp(-\psi_i[k]/\tau_1)}, \quad p_f[s] = \frac{\exp(I_s/\tau_2)}{\sum_{k=0}^{n_m-1}\exp(I_k/\tau_2)}.$$

### ⚪ **CodeFP**：检索功能基序指导序列—结构协同从头设计
- **paper**：[**Co-Generative De Novo Functional Protein Design**](https://openreview.net/forum?id=O4BmkfXv1f)

按基因本体（GO）功能标签从头设计蛋白质时，抽象文本标签很难直接约束三维几何，而“先生成主链再逆折叠”的两步法又常因忽略序列约束导致无法折叠回目标结构。**CodeFP** 基于多模态离散吸收扩散模型 DPLM-2（将氨基酸序列 $s$ 与 LFQ 离散结构词元 $z$ 同步掩码去噪，生成损失为 $\mathcal L_{\text{gen}}$），提出了两个关键模块把功能标签锚定到局部三维结构上：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-075-codefp.png)

1. **功能—结构基序检索（FSR）**：离线用 InterProScan 定位训练集中每个“蛋白—GO 对” $(P_i, y)\in\mathcal S_y$ 对应的局部功能结构域主链片段，经 LFQ 离散化与冻结编码器提取 `[CLS]` 表征 $e_{i,y}$ 并取均值，构建功能 $y$ 的几何基序质心 $c_y$；生成时检索目标功能集 $Y_{\text{in}}$ 对应的质心集合 $C=\{c_y\mid y\in Y_{\text{in}}\}$，通过交叉注意力注入第 $l$ 层隐状态 $H^{(l)}$：
   $$c_y = \mathrm{Mean}\Big(\big\{e_{i,y} \;\big|\; (P_i, y)\in\mathcal S_y\big\}\Big), \qquad H^{(l)\prime} = H^{(l)} + \mathrm{CrossAttn}\big(Q = H^{(l)},\, K = C,\, V = C\big).$$
2. **局部结构—功能潜空间监督（LSFS）**：由于局部三维结构词元化受全局拓扑影响，同一功能基序常映射为多种不同的离散结构词元序列而引发训练歧义。模型直接对末层连续隐状态 $H^{(L)}$ 中属于功能结构域的词元做均值池化，预测 $C$ 类 GO 概率 $\hat p_y$，并引入均值归一化逆类别频率权重 $w_c$（$N_c$ 为类别频次）构建加权交叉熵辅助损失：
   $$w_c = \frac{N_c^{-1}}{\frac1C\sum_{j=1}^C N_j^{-1}}, \qquad \mathcal L_{\text{LSFS}} = -w_y\log\hat p_y, \qquad \mathcal L_{\text{total}} = \mathcal L_{\text{gen}} + \gamma\mathcal L_{\text{LSFS}}.$$

### ⚪ **FIDIA**：直接优化 Best-of-N 目标的蛋白质逆折叠强化学习
- **paper**：[**FIDIA: Function-Informed Sequence Design via Inference-Aligned Policy Optimization**](https://openreview.net/forum?id=pvbJsa0ia0)

用强化学习微调 ProteinMPNN 等逆折叠策略 $\pi_\theta(s\mid\mathbf x, c)$ 时，常规 RL 优化的是采样序列的“平均奖励”，但实际湿实验筛选采用的是 **Best-of-$N$（BoN，独立采样 $N$ 条候选序列只保留最高分的一条 $s^*$）**。**FIDIA** 直接将优化目标对齐到 BoN 期望最大回报 $\mathcal J_{\text{BoN}}(\theta) = \mathbb E_{s^*\sim\pi_{\text{bon}}}[R(s^*)]$。

为了在不引入不可微 $\max$ 算子的前提下低方差估计梯度，每次从旧策略 $\pi_{\theta_{\text{old}}}$ 采样 $K>N$（如 $K=16, N=8$）条长度为 $T_i$ 的候选序列，按复合功能奖励（基序与全局重折叠 RMSD 柯西核 + AutoDock Vina 对接能 + 多样性）升序排列为 $R(s_{(1)})\le\dots\le R(s_{(K)})$。利用 U-统计量遍历所有大小为 $N$ 的子集，第 $i$ 个排序样本在任意 $N$ 元子集中成为最大值的组合概率为 $p_i = \binom{i-1}{N-1}/\binom{K}{N}$（对 $i<N$ 恒为 $0$），由此解析推导出协同强化胜者及其支撑下水平集的秩权重 $\lambda_i$ 与标准化优势函数 $A_i$：
$$\nabla_\theta\mathcal J_{\text{BoN}} \approx \sum_{i=1}^K \lambda_i\nabla_\theta\ln\pi_\theta\big(s_{(i)}\big), \qquad \lambda_i = p_i R\big(s_{(i)}\big) + (N-1)\sum_{j=i+1}^K \frac{p_j}{j-1}R\big(s_{(j)}\big), \qquad A_i = \frac{\lambda_i - \bar\lambda}{\sigma_\lambda}.$$
记词元级重要性采样概率比为 $\rho_{i,t}(\theta) = \frac{\pi_\theta(r_{i,t}\mid S_{i,t})}{\pi_{\theta_{\text{old}}}(r_{i,t}\mid S_{i,t})}$，将 $A_i$ 嵌入带裁剪的 GRPO 代理目标更新策略，会自动对 $i<N$ 的非竞争样本施加负优势抑制，并对顶尖样本赋予超线性正向激励：
$$\mathcal J(\theta) = \mathbb E_{s\sim\pi_{\theta_{\text{old}}}}\!\left[\frac1K\sum_{i=1}^K\frac{1}{T_i}\sum_{t=1}^{T_i}\min\Big(\rho_{i,t}(\theta)A_i,\; \mathrm{clip}\big(\rho_{i,t}(\theta), 1-\varepsilon, 1+\varepsilon\big)A_i\Big)\right].$$

### ⚪ **SWITCHCRAFT**：用共折叠预测器反向传播设计多态构象开关蛋白
- **paper**：[**SWITCHCRAFT: A Programmatic Framework for Designing State-Switching Proteins**](https://openreview.net/forum?id=YtqaHnqv8c)

如何设计一条单一氨基酸序列，使其在游离态（apo）和结合配体效应物态（holo）之间发生预期的别构构象切换？**SWITCHCRAFT** 不训练新的生成模型，而是将长度为 $L$ 的待设计序列参数化为连续对数几率 $z\in\mathbb R^{20\times L}$，分别与多个状态的分子上下文 $\{C_s\}_{s=1}^{N_{\text{states}}}$ 送入全原子共折叠结构预测器 **Boltz-1**，在其输出的成对残基/配体距离分布图 $D_{ij}$（第 $k$ 个距离分箱概率为 $p_{ijk}$，分箱中点为 $d_k$；记截断条件香农熵为 $H_{<d_0}(D_{ij}) = -\mathbb E[\log P(D_{ij})\mid D_{ij}<d_0]$，用于同时鼓励截断半径内距离分布的低熵锐化与高接触概率）上编程式组合四类损失原语并反向传播更新序列：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-076-switchcraft.png)

1. **基序保持与反基序损失**：约束状态 $C_s$ 下功能基序位点集 $m$ 的预测距离逼近目标基序坐标 $r$ 的真实距离（或乘 $-0.5$ 在特定状态下主动破坏基序）：
   $$\mathcal L_{\text{motif}}(z; C_s, m) = \sum_{\substack{i,j\in m \\ i\neq j}}\sum_k \frac{p_{ijk}}{|m|(|m|-1)}\big(d_k - \|r_i - r_j\|\big)^2, \qquad \mathcal L_{\text{anti-motif}} = -0.5\,\mathcal L_{\text{motif}};$$
2. **配体结合与反结合损失**：最小化配体最紧密的前 $c$ 个词元各自最近 2 个蛋白残基在 $<20\,\text{\AA}$ 内的截断距离熵 $\mathcal L_{\text{binding}}$（或乘 $-0.5$ 抑制非期望结合）；
3. **跨状态构象变化损失**：最大化两个状态上下文 $C_1, C_2$ 之间每个残基 $i$ 最敏感成对距离分布的 Jensen-Shannon 散度（JSD），驱动显著的别构构象重排：
   $$\mathcal L_{\text{conf-change}}(z; C_1, C_2) = -\frac1L\sum_{i=1}^L\max_{j\in[1,L]}\mathrm{JSD}\!\left(D_{ij}^{(1)}\,\middle\|\,D_{ij}^{(2)}\right);$$
4. **状态内折叠接触损失**：最小化长程残基（$|i-j|\ge 9$）在 $<14\,\text{\AA}$ 内的截断熵 $\mathcal L_{\text{contact}}(z; C_s) = \frac1L\sum_{j=1}^L\min_{i:|i-j|\ge 9} H_{<14\,\text{\AA}}(D_{ij})$ 以保证各态自身折叠紧凑。

配合软分布 $z_{\text{soft}}=\mathrm{softmax}(z/\tau)$ 与直通估计器（STE）的四阶段温度退火优化，该方法成功设计出了经生物膜干涉（BLI）湿实验验证的 $\text{Zn}^{2+}$ 依赖型 PD-L1 结合开关（无锌不结合、加锌后 $K_D = 746\,\text{nM}$）以及小分子响应的从头 cpGFP 荧光生物传感器。

### ⚪ **Chamaileon**：结合协同设计与前向折叠的多靶点/多态结合剂生成
- **paper**：[**Chamaileon: Cross-Context Binder Design with Contextualized Modeling and Mixed Sampling**](https://openreview.net/forum?id=JAQ9bm0Rp4)

$$\mathcal L_{\text{I3CD}}(\theta) = \mathbb E\!\left[\sum_{d=1}^D\left(\frac{\big\|\hat x_1^{B,d} - x_1^d\big\|^2}{1-t} + \frac{\big\|\log_{r_t^d}(\hat r_1^d) - \log_{r_t^d}(r_1^d)\big\|^2}{1-t} - \log p_\theta\big(a_1^d \mid \mathcal B_{t,\tilde t}, \mathcal T_{1,1}, M_H\big)\right)\right].$$
借此，单一模型同时具备序列—结构协同设计（$t, \tilde t$ 同步演化）与序列条件化前向折叠（令序列时间步 $\tilde t=1$ 输入干净序列、仅演化结构 $t$）的能力。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-078-mops.png)

推理时提出**混合路径采样（MoPS）**：在 $K$ 个靶标上下文 $\{\mathcal T_{1,1}^0, \dots, \mathcal T_{1,1}^{K-1}\}$ 之间划分时间区间循环接力——在当前区间内，构象 $m$ 执行协同去噪更新结构 $(x_t^m, r_t^m)$ 与共享序列 $a_t^m$，并提取预测出的干净氨基酸序列 $\hat a_1^m$；随后以 $\hat a_1^m$ 为条件驱动下一构象 $n=(m+1)\bmod K$ 执行序列条件化前向折叠（输入 $\mathcal B_{t,1}^n = (x_t^n, r_t^n, \hat a_1^m)$）追赶至同一时间步并对齐共享序列。再配合将平移流转换为 SDE 的多假设束搜索（用 AF2-Multimer 评估 ipAE、pLDDT 与 scRMSD 剪枝），无需多态复合物训练数据即可生成跨上下文兼容的结合剂。

### ⚪ **L3-PPI**：引入虚拟 L3 路径图提示的通用 PPI 预测头
- **paper**：[**Learning the Interaction Prior for Protein-Protein Interaction Prediction: A Model-Agnostic Approach**](https://openreview.net/forum?id=p7PPMKTPJp)

生物网络中有一条重要的“$L_3$ 规则”：两个蛋白质之间跳数为 3 的路径（$u \to v_1 \to v_2 \to v$，对应凹凸互补结合界面）越多，结合似然越高。但在归纳式（BFS/DFS 划分）测试中，未见蛋白与主网络断开，无法直接统计真实 $L_3$ 路径。**L3-PPI** 提出一种即插即用、模型无关的图提示学习（Graph Prompt Learning）分类头：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-080-l3ppi.png)

1. **代理模型预训练**：先在训练 PPI 网络上用深度优先搜索收集已知正负样本对之间的真实 $L_3$ 子图，用二元交叉熵预训练一个判别 $L_3$ 模式图有效性的图同构网络 $\mathrm{GNN}_{\text{pre}}(G; \theta^*, \phi^*)$ 并冻结；
2. **虚拟 $L_3$ 图提示与稀疏门控**：给定任意冻结基座编码器 $\mathcal M$ 提取的待测蛋白对表征 $(\mathcal M(P_u), \mathcal M(P_v))$，在 $(u, v)$ 之间插入 $K+1$ 个可学习的跨样本共享虚拟中间蛋白节点，构成 $K$ 条候选虚拟 $L_3$ 子图路径 $\{\mathrm{path}_i\}_{i=1}^K$（每条包含 $\{u, v_i^P, v_0^P, v\}$）。用门控图网络计算每条路径的激活概率 $p_i = \mathrm{GNN}_{\text{gpt}}(\mathrm{path}_i)$，经带温度 $\tau$ 的 Gumbel-Softmax 松弛赋予软边权组装成提示模式图 $G_F$，送入冻结的 $\mathrm{GNN}_{\text{pre}}$ 输出预测 $\tilde y_{\text{gpt}}$；
3. **路径数量先验正则化（$\mathcal L_{\text{PN}}$）与两阶段优化**：在分类损失之外引入超参数 $\gamma>1$ 的铰链损失，显式约束正相互作用对（$y_{\text{gpt}}=1$）激活更多虚拟 $L_3$ 路径、负样本对（$y_{\text{gpt}}=0$）激活路径稀疏，并配合“先保留全部路径训练虚拟节点提示嵌入、收敛后再开启门控网络联合微调”的两阶段策略实现稳定优化：
   $$\mathcal L_{\text{PN}} = \begin{cases} \displaystyle\max\!\left(0,\; K\!\left(1 - \frac1\gamma\right) - \sum_{i=1}^K p_i\right), & \text{if } y_{\text{gpt}} = 1, \\[8pt] \displaystyle\max\!\left(0,\; \sum_{i=1}^K p_i - \frac{K}{\gamma}\right), & \text{if } y_{\text{gpt}} = 0. \end{cases}$$

### ⚪ **MMM-PPI**：融合残基、基序与蛋白三尺度的多模态 PPI 预测
- **paper**：[**Enhancing Protein-Protein Interaction Prediction with Hierarchical Motif-based Multimodal Protein Embedding**](https://openreview.net/forum?id=goPaAYr1J3)

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-081-mmmppi.png)

2. **中观基序尺度**：用 FIMO 算法（基于 PROSITE PSSM 矩阵）离线扫描定位蛋白 $P_a$ 的 $a_k$ 个显著功能基序，将每个基序内部的多模态残基表征求和得到基序向量 $\mathbf h_{M_{a_j}}$，构成基序矩阵 $H_a = [\mathbf h_{M_{a_1}}, \dots, \mathbf h_{M_{a_k}}]\in\mathbb R^{D\times a_k}$；
3. **宏观蛋白尺度（上下文协同注意力）**：预测蛋白对 $(P_a, P_b)$ 时，令两蛋白全局残基和向量 $\mathbf h_{P_a} = \sum_v\mathbf h_v$ 的哈达玛积作为交互上下文 $\mathbf m_{ab} = \mathbf h_{P_a}\odot\mathbf h_{P_b}\in\mathbb R^D$，动态计算各自基序的注意力权重 $\beta_{a\mid b}$ 以生成伙伴特异的宏观表征 $\tilde{\mathbf h}_{a\mid b}$：
   $$\mathbf h_{a\mid b} = \tanh\!\big(W_a^q H_a\big) \odot \tanh\!\big(W_a^m \mathbf m_{ab}\big), \qquad \beta_{a\mid b} = \mathrm{softmax}\!\big(\mathbf w_a^\top \mathbf h_{a\mid b}\big), \qquad \tilde{\mathbf h}_{a\mid b} = \tanh\!\big(H_a\beta_{a\mid b}^\top\big).$$
预训练好该编码器后冻结，聚合各蛋白在训练集邻居上下文下的条件表征作为初始节点特征，送入上层 GIN 网络完成多标签 PPI 分类。

### ⚪ **PPI-Candidate-Ranking**：结合接触图激活检索与多源证据的 PPI 候选重排序
- **paper**：[**PPI Candidate Ranking: Large-Scale Evaluation of a Domain Knowledge-Guided Pipeline**](https://openreview.net/forum?id=JRsQDPWFCC)

在全蛋白质组候选池 $CP(p)$ 中为目标蛋白 $p$ 寻找新相互作用伙伴时，直接按序列 PPI 预测器的标量概率排序，真正的新伙伴往往排在数千名之后。该工作针对跨时间版本数据库更新（如从 STRING v11 前瞻性预测 v12 新增互作），设计了两阶段领域知识引导的优先级排序流水线：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-082-ppirank.png)

1. **阶段 I（接触图激活区域引导的子序列检索）**：假设新结合伙伴遵循与已知伙伴 $p_k\in KP(p)$ 相似的局部结合机制。先用预训练 D-SCRIPT 提取目标蛋白、已知伙伴与候选蛋白的残基级嵌入 $z_p, z_k, z_c$ 以及 $p$ 与各已知伙伴 $p_k$ 的预测残基接触概率矩阵 $C(p, p_k)$；计算 $p_k$ 上各残基的最大接触概率轮廓 $a_j^{(k)} = \max_i C(p, p_k)_{i,j}$ 并扫描提取平均激活最高的连续残基片段区间 $I_k$（长度 $|I_k|$）。随后将展平的锚点活性区嵌入 $z_k[I_k]$ 作为滑动窗口模板，与候选蛋白 $p_c\in CP(p)$（长度 $n_c$）上所有等长连续片段 $z_c[i : i + |I_k|]$ 计算最大余弦相似度，并在全体已知伙伴上取最大值作为初级检索得分 $R_p(p_c)$：
   $$\mathrm{sim}(p_c, p_k) = \max_{0\le i < n_c - |I_k|}\frac{\big\langle z_k[I_k],\, z_c[i : i + |I_k|]\big\rangle}{\|z_k[I_k]\|_2\cdot\|z_c[i : i + |I_k|]\|_2}, \qquad R_p(p_c) = \max_{p_k\in KP(p)}\mathrm{sim}(p_c, p_k).$$
2. **阶段 II（多源生物证据重排序）**：截取每个锚点的 Top-10 高分候选，融合 D-SCRIPT 标量交互分、SpeedPPI 三维复合物对接质量得分（$\mathrm{pDockQ}$）、UniProt 功能与亚细胞定位注释的 TF-IDF/Jaccard 重叠度，以及采用按蛋白分组 `GroupKFold`（防止跨折蛋白泄漏）微调的 **PubMedBERT 交叉编码器**进行重排序，在 STRING v11$\to$v12 上将早期召回指标（Recall@10 与 MRR）提升了高达两个数量级，并在消除共表达/共定位捷径偏置的外部严格基准 PiNUI 上将再发现覆盖率从 $0.0080$ 提升至 $0.3849$。

## 4.1 DNA 甲基化与多模态

<a id="p-066"></a>
### ⚪ **MOJO**：兼容模态缺失的 RNA-seq 与 DNA 甲基化双模态预训练
- **paper**：[**Bimodal masked language modeling for bulk RNA-seq and DNA methylation representation learning**](https://openreview.net/forum?id=fi4gh4Syka)

肿瘤学中的 Bulk RNA-seq 与 DNA 甲基化微阵列数据维度极高，且临床部署时常面临单模态缺失或跨芯片平台迁移问题。**MOJO** 首先依据芯片注释将关联至同一基因 $g$ 的所有 CpG 位点集合 $\mathrm{sites}(g)$ 按区域权重 $w(s)$ 加权平均：$X_{\text{meth}}[g] = \frac{\sum_{s\in\mathrm{sites}(g)} w(s)X_{\text{sites\_meth}}[s]}{\sum_{s\in\mathrm{sites}(g)} w(s)}$，转化为与具体微阵列芯片无关的基因级甲基化特征；再与对数变换后的基因表达量一起经线性等距分箱离散化为双模态词元序列 $\tilde X = (\tilde X_{\text{rna}}, \tilde X_{\text{meth}})$。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-061-mojo.png)

为规避在上万个基因上直接计算二次方自注意力的显存瓶颈，主干网络采用 **U-Net 卷积—注意力混合架构**：先用多级步长为 2 的一维卷积塔对基因序列做大幅度长度下采样，在低维压缩潜空间通过多头自注意力 Transformer 融合双模态上下文后，再由带跨层跳跃连接的反卷积上采样塔恢复至原始基因长度，在随机掩码位点集 $M_m$ 上优化双模态掩码语言建模（MLM）交叉熵损失。

在下游微调（泛癌种分类与生存分析）时，当测试样本缺失某一模态时直接将该模态全序列填充为 `<MASK>`。为提升单模态缺失下的预测鲁棒性，微调阶段对每个完整双模态样本 $x$ 同时构造完整（$\text{rna+meth}$）、仅保留 RNA（$\text{rna}$）和仅保留甲基化（$\text{meth}$）三种模态可用状态 $m\in D_{\text{modality}}$，通过最小化下游任务预测输出 $f_\theta(x, m)$ 与模态指示变量 $m$ 之间的**互信息（MI）**，促使分类器输出分布独立于模态缺失状态：
$$\mathcal L_{\text{total}} = \mathcal L_{\text{task}}\big(f_\theta(x; \text{rna+meth}),\, y\big) + \lambda\cdot\mathbb E_{m\in D_{\text{modality}}}\Big[\mathrm{MI}\big(f_\theta(x, m),\, m\big)\Big].$$

## 5.1 虚拟细胞与扰动

<a id="p-067"></a>
### ⚪ **scBIG**：先聚类基因模块再做条件流匹配的单细胞扰动预测
- **paper**：[**Beyond Independent Genes: Learning Module-Inductive Representations for Single-Cell Gene Perturbation Prediction**](https://openreview.net/forum?id=onuLk72nRw)

单细胞扰动响应是以“基因功能模块”为单位协同变化的，把上万个基因当成独立扁平词元既慢又忽略了程序级协同调控。**scBIG** 分三步建模：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-043-scbig.png)

1. **最优传输基因模块划分（GRC）**：结合单细胞基础模型（GeneCompass）提取的基因语义嵌入 $E_i$ 与 STRING 蛋白互作二值邻接矩阵 $A^{\text{PPI}}$，定义基因 $i$ 到模块质心 $\mu_k$ 的代价矩阵 $C_{ik} = (1 - \cos(E_i, \mu_k)) + (1 - \frac{1}{|c_k|}\sum_{j\in c_k} A_{ij}^{\text{PPI}})$，通过均匀边缘约束下的 Sinkhorn 最优传输将 $G$ 个基因均衡划分为 $K$ 个等容量的功能模块；
2. **诱导点瓶颈编码（GCAE）**：引入 $M<K$ 个可学习诱导点，通过 Perceiver 式的“压缩—自注意力—广播”交叉注意力瓶颈，以线性复杂度捕获跨模块交互并池化为细胞级潜表征 $z$；
3. **结构感知条件流匹配**：用小批量最优传输配对对照细胞潜码 $z_0$ 与扰动细胞潜码 $z_1$（插值 $z_t = (1-t)z_0 + t z_1$），以 ESM2（基因扰动）或 ChemBERTa（药物扰动）编码条件 $c$ 训练速度场 $v_\theta$。为保证 ODE 积分并解码出的预测表达谱 $\hat x_1\in\mathbb R^G$ 保持共调控结构，定义按模块聚合的簇级表达向量 $\bar{\hat x}_1\in\mathbb R^K$ 及模块间皮尔逊相关矩阵 $R(\cdot)\in\mathbb R^{K\times K}$，并引入 Reactome 二值通路归属矩阵 $S\in\{0,1\}^{P\times G}$，在流匹配损失之外联合优化**簇相关性矩阵对齐**与**通路激活分布的熵正则化 Sinkhorn 距离 $W_\epsilon$**（$R_{\text{gt}}^*, S_{\text{gt}}^*$ 为真实扰动目标统计量）：
   $$\mathcal L = \mathbb E_{t, z_0, z_1}\big\|v_\theta(z_t, t, c) - (z_1 - z_0)\big\|^2 + \lambda_{\text{corr}}\big\|R(\bar{\hat x}_1) - R_{\text{gt}}^*\big\|_F + \lambda_{\text{pathway}}W_\epsilon\big(S\hat x_1,\, S_{\text{gt}}^*\big).$$

### ⚪ **ADAPERT**：抽取扰动条件子图并分离背景噪声的转录响应预测
- **paper**：[**Learning Adaptive Perturbation-Conditioned Contexts for Robust Transcriptional Response Prediction**](https://openreview.net/forum?id=aJVkQAd7tv)

单细胞基因扰动中真正发生显著差异表达的基因（DEGs）仅占总基因的 1%~10%，直接在全基因上算 MSE 会被海量未变化基因主导，导致预测偏移向零收缩（均值坍缩）；同时在完整静态 PPI 图上传播也会引入大量无关通路噪声。**ADAPERT** 从模型和损失两端改进：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-044-adapert.png)

1. **可微扰动条件子图抽取**：将 STRING PPI 图经消息传递提取的基因节点特征 $h_v$ 与大模型（GPT-4o / GenePT）编码的扰动靶基因 $p$ 文本描述投影 $\tilde s_p$ 拼接，计算相关性得分并经 Gumbel-Softmax 采样筛选高相关节点诱导稀疏子图 $\mathcal G_p$，求和得到扰动上下文表征 $z_{\text{context}}^{(p)}$，与对照细胞表征一起送入解码器预测扰动后表达 $\hat X^p$；
2. **自适应信噪分离损失**：对每个训练扰动 $p$ 按统计检验（BH 校正 $q_i^{(p)} < 0.05$）划分显著响应集 $\mathcal D(p)$ 与非响应背景集 $\bar{\mathcal D}(p)$。对非响应基因的预测偏移 $\Delta\hat X_i^p = \hat X_i^p - X_i^c$ 施加阈值为 $\delta$ 的 **Huber 惩罚** $\rho_\delta(r)$（$|r|\le\delta$ 时为 $\frac12 r^2$，否则为 $\delta(|r|-\frac12\delta)$）以强力压缩微小虚假波动并防离群噪声主导；同时构造仅保留真实 DEG 偏移、将非 DEG 置零的净响应向量并经投影头映射为 $t^{(p)}$，在单位球面上与抽取的子图上下文 $z_{\text{context}}^{(p)}$ 对齐：
   $$\mathcal L_{\text{total}} = \mathbb E\big[\|\hat X^p - X^p\|_2^2\big] + \lambda_{\text{non}}\mathbb E_p\!\left[\sum_{i\in\bar{\mathcal D}(p)}\rho_\delta\big(\Delta\hat X_i^p\big)\right] + \lambda_{\text{align}}\mathbb E\!\left[\left\|\frac{z_{\text{context}}^{(p)}}{\|z_{\text{context}}^{(p)}\|_2} - \frac{t^{(p)}}{\|t^{(p)}\|_2}\right\|_2^2\right].$$

<a id="p-069"></a>
### ⚪ **Needles in the Haystack**：解决单细胞扰动评测中的信号稀释与均值坍缩
- **paper**：[**Needles in the Haystack: Addressing Signal Dilution Improves scRNA-seq Perturbation Response Modeling and Evaluation**](https://openreview.net/forum?id=XsrXLPxBJw)

在许多 Perturb-seq 基准上，“忽略输入扰动条件、直接输出全部扰动细胞的平均表达谱 $\mu^{\text{all}}$”竟然在常规指标下反超深度生成模型。作者通过负二项分布模拟指出根源有二：（1）**信号稀释**：真实受扰动基因极度稀疏（如 Replogle22 中中位显著 DEG 仅占 0.05%），无权重 MSE 天然偏袒方差小的常数均值预测；（2）**对照系统偏差**：未扰动对照细胞均值 $\mu^c$ 与全体扰动中心 $\mu^{\text{all}}$ 存在系统性批次偏移，以 $\mu^c$ 为参考计算表达变化量会被共性偏移 $\mu^{\text{all}} - \mu^c$ 主导，从而虚假抬高 $\mathrm{Pearson}(\Delta)$。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-045-wmse.png)

为此，论文提出一套抗偏差评估与训练方案：摒弃对照细胞参考，对每个扰动 $p$ 以**其余所有扰动细胞（vs. Rest）**为参考系执行 $t$ 检验，将基因 $i$ 的统计量绝对值 $|t_i|$ 最小—最大归一化为 $\tilde t_i\in[0,1]$ 后平方构造和为 1 的基因权重 $w_i = \tilde t_i^2 / \sum_{j=1}^g \tilde t_j^2$；并以全体扰动均值 $\mu^{\text{all}}$ 为原点定义真实偏移 $\Delta_i = \mu_i^p - \mu_i^{\text{all}}$ 与预测偏移 $\hat\Delta_i = \hat\mu_i^p - \mu_i^{\text{all}}$（记加权均值为 $\bar\Delta_w = \sum_i w_i\Delta_i$），提出**加权均方误差（WMSE）**与**加权决定系数 $R_w^2(\Delta)$**：
$$\mathrm{WMSE} = \sum_{i=1}^g w_i\big(\mu_i^p - \hat\mu_i^p\big)^2, \quad R_w^2(\Delta) = 1 - \frac{\sum_{i=1}^g w_i(\Delta_i - \hat\Delta_i)^2}{\sum_{i=1}^g w_i(\Delta_i - \bar\Delta_w)^2}.$$
在此定义下，当模型退化为输出常数均值猜测 $\hat\mu_i^p = \mu_i^{\text{all}}$（即 $\hat\Delta_i=0$）时，$R_w^2(\Delta)\big|_{\hat\mu^p = \mu^{\text{all}}} = 1 - \frac{\sum_i w_i\Delta_i^2}{\sum_i w_i\Delta_i^2 - \bar\Delta_w^2} \le 0$ 恒成立。同时，在训练集内预计算权重 $\{w_i\}$ 将 WMSE 直接作为监督损失替代标准 MSE 训练现有模型（GEARS、scGPT 等），即可有效抑制向均值坍缩并恢复跨扰动的真实方差。

### ⚪ **PerturbDiff**：在 RKHS 空间对整个细胞分布做泛函扩散
- **paper**：[**PerturbDiff: Functional Diffusion for Single-Cell Perturbation Modeling**](https://openreview.net/forum?id=yBAqonxCdp)

单细胞测序具有破坏性，且同一扰动条件下的细胞群体本身是一个概率测度。**PerturbDiff** 将扩散模型的随机变量从“单个细胞”提升为**“整个细胞概率分布”**：给定大小为 $m$ 的扰动细胞小批量 $B_0=\{x_1,\dots,x_m\}$（诱导经验分布 $\tilde P_{B_0} = \frac1m\sum_{j=1}^m\delta_{x_j}$），利用能量距离正定核 $k(\cdot,\cdot)$ 将其映射为再生核希尔伯特空间（RKHS $\mathcal H_k$）中的核均值嵌入 $\mu_0 = \frac1m\sum_{j=1}^m k(x_j, \cdot)\in\mathcal H_k$。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-046-pertubdiff.png)

论文从理论上证明：直接在原始细胞空间对小批量中每个细胞注入独立标准高斯噪声 $B_t = \sqrt{\alpha_t}B_0 + \sqrt{1-\alpha_t}\varepsilon$，在一阶泰勒展开下等价于在无穷维空间 $\mathcal H_k$ 上施加协方差算子为 $C = \frac{1}{m^2}\sum_{j=1}^m T_j T_j^*$（其中 $T_j v = \nabla_x k(x_j, \cdot)^\top v$）的迹类高斯随机元素。去噪网络采用双流 **MM-DiT** 架构（将每个单细胞视为一个词元、整个细胞批次视为一条序列，并行维护加噪扰动细胞流与对照细胞流 $B_{\text{ctrl}}$），输出预测扰动批次 $B_\theta = \{x_1^\theta, \dots, x_m^\theta\}$（对应经验分布 $\tilde P_{B_\theta}$ 与核均值嵌入 $\mu_\theta$）。利用 RKHS 范数平方与能量距离（ED / MMD）的严格等价性，训练目标结合分布级能量距离（式中 $X, X'\stackrel{\text{i.i.d.}}{\sim}\tilde P_{B_0}$，$Y, Y'\stackrel{\text{i.i.d.}}{\sim}\tilde P_{B_\theta}$）与锚定批次质心的逐细胞均方误差：
$$\mathcal L_{\text{total}} = \underbrace{2\mathbb E\|X - Y\| - \mathbb E\|X - X'\| - \mathbb E\|Y - Y'\|}_{\mathcal L_{\text{MMD}} = \|\mu_0 - \mu_\theta\|_{\mathcal H_k}^2 = \mathrm{ED}(\tilde P_{B_0},\, \tilde P_{B_\theta})} + \lambda_{\text{MSE}}\frac1m\sum_{j=1}^m\big\|x_j - x_j^\theta\big\|_2^2.$$
此外，通过将对照流置零，模型支持先在 6000 万未扰动细胞图谱（CellxGene）上做边缘分布生成预训练，再迁移至下游学习扰动诱导的群体分布偏移。

### ⚪ **PerturbedVAE**：解耦不变背景与因果响应子空间的单细胞扰动模型
- **paper**：[**What Makes a Representation Good for Single-Cell Perturbation Prediction?**](https://openreview.net/forum?id=5cLRC1hrTP)

论文首先提出**扰动抑制假说**：常规单细胞基础模型因拟合全局边缘分布，会将占主导地位的未变化背景程序编码进主成分，反而把极度稀疏的扰动特异信号压制掉（其冻结特征对扰动标签的线性探测准确率甚至低于 PCA）。为此，**PerturbedVAE** 将给定细胞观测 $x$ 与扰动标签 $u$ 下的潜变量 $z=(z_\iota, z_\nu)$ 显式拆解为两个子空间：捕获稳定细胞背景的**扰动不变块 $z_\iota\in\mathbb R^{d_\iota}$**，以及遵循有向无环图（DAG）因果拓扑的**扰动响应块 $z_\nu\in\mathbb R^{d_\nu}$**。生成过程由严格下三角邻接矩阵 $\lambda_{\iota\iota}, \Lambda_{\nu\nu}(u)$、跨块耦合矩阵 $\Lambda_{\nu\iota}(u)$、外生高斯噪声 $n_\iota, n_\nu(u)$ 及平滑可逆解码映射 $g$ 定义：
$$z_\iota := \lambda_{\iota\iota}z_\iota + n_\iota, \quad z_\nu := \Lambda_{\nu\iota}(u)z_\iota + \Lambda_{\nu\nu}(u)z_\nu + n_\nu, \quad x := g(z).$$
由于 $\Lambda_{\nu\nu}(u)$ 为对角线全零的严格下三角矩阵，$\det(I - \Lambda_{\nu\nu}(u)) \equiv 1$，无需显式矩阵求逆即可通过三角方程组求解闭式条件高斯先验 $p_\phi(z_\nu\mid u, z_\iota)$。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-047-pertubedvae.png)

训练时，为防止主导背景信号侵占响应块 $z_\nu$，给每个扰动样本 $(x, u)$ 配对采样一个未扰动对照细胞 $x^{(u_0)}$，在变分证据下界 $\mathcal L_{\text{ELBO}}(x, u)$ 之外施加不变块表征对比对齐损失：
$$\mathcal L = -\mathcal L_{\text{ELBO}}(x, u) + \alpha\big\|z_\iota - z_\iota^{(u_0)}\big\|_2^2.$$
作者从理论上证明：在环境充分性与干预充分性条件下，该设计严格保证不变块 $z_\iota$ 线性块可识别（$z_\iota = A_\iota\hat z_\iota + c_\iota$）、响应块 $z_\nu$ 逐分量置换与缩放可识别（$z_\nu = P_\nu\hat z_\nu + c_\nu$）。

<a id="p-073"></a>
### ⚪ **scDEBART**：直接在大规模差异表达（logFC）谱上预训练扰动模型
- **paper**：[**scDEBART: Predicting in silico Single-Cell Perturbation Responses via Large-Scale Differential Expression Learning**](https://openreview.net/forum?id=pJyidZg93y)

常规单细胞基础模型通过掩码预测细胞内的“静态绝对表达量”，事后将预测值相除算对数倍数变化（logFC）时极易被测序脱扣（dropout）伪影主导。**scDEBART** 将预训练范式直接重构为：**在给定基线表达条件下，直接预测群体间的差异表达对数倍数变化（logFC）**。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-049-scdebart.png)

作者从 CELLxGENE 的 6660 万个正常细胞中聚类出近 10 万个转录一致簇，用 scVI 后验去噪并筛除低非零检出率（$<0.3$）的基因后，构建了 628 万条高质量簇间差异表达谱（记录各基因 $g_i$ 的基线去噪表达 $\mu_i$ 与后验中位数对数倍数变化 $x_i$）。模型将 MSigDB 通路先验、BioBERT 基因功能文本嵌入、基线表达 $\log(1+\mu_i)$ 和 $x_i$ 拼接映射为输入表征 $h_i$，随机掩码 15% 基因的 $x_i$，用双向编码—自回归解码的 **BART** 架构预训练恢复掩码位点的倍数变化 $\hat x_i$ 与嵌入 $\hat h_i$。

下游 Perturb-seq 微调时，只需在输入端将原本的 $x_i$ 替换为大幅值扰动指示符 $p_i$（CRISPRi 敲降靶基因设为 $-10.0$，CRISPRa 激活靶基因设为 $+10.0$，其余未直接受扰基因设为 $0.0$）。记全集 $N$ 个基因的真实对数倍数变化向量为 $x^* = (x_{g_1}^*, \dots, x_{g_N}^*)$、模型预测向量为 $\hat x$，微调阶段联合优化放大高响应基因权重的加权均方误差与全局/前 20% 高响应基因的可微皮尔逊相关系数损失（$\rho_{\text{global}}, \rho_{\text{top}}$）：
$$\mathcal L_{\text{finetune}} = \alpha\cdot\frac1N\sum_{i=1}^N\big(1 + \lambda|x_{g_i}^*|\big)\big(\hat x_{g_i} - x_{g_i}^*\big)^2 + \gamma\cdot\Big(1 - \big[\beta\rho_{\text{global}}(\hat x, x^*) + (1-\beta)\rho_{\text{top}}(\hat x, x^*)\big]\Big).$$

## 5.2 单细胞生成与编辑

<a id="p-074"></a>
### ⚪ **scDiVa**：联合建模基因身份与表达量的单细胞掩码离散扩散模型
- **paper**：[**ScDiVa: Masked Discrete Diffusion for Joint Modeling of Single-Cell Identity and Expression**](https://openreview.net/forum?id=Sm7NhztxlA)

单细胞转录组本身是无序多重集，用自回归模型生成会强加单向因果顺序偏置。**scDiVa** 在 5916 万个单细胞上构建了基于吸收态的双向非因果掩码离散扩散基础模型。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-050-scdiva.png)

1. **熵归一化基因筛选与潜锚点**：为避免高表达但无细胞类型区分度的看家基因占满上下文窗口（$L_{\max}=1200$），在全局语料上计算每个基因 $g_k$ 表达分布的群体香农熵 $H(g_k)$，按熵归一化得分 $r_k = \frac{v_k}{H(g_k) + \epsilon}$ 降序截断生成初始基因词元序列 $x_0 = [x_0^1, \dots, x_0^L]$ 及对数表达值 $v = [v_1, \dots, v_L]$，并在序列首部前置一个永不掩码的全局潜变量锚点词元 `[LAT]`；
2. **吸收态扩散与双头去噪**：在连续时间 $t\in[0,1]$ 上，前向过程以概率 $t$ 独立将每个位置的基因词元替换为吸收态掩码符号 $\varnothing$（`[MASK]`）并将对应表达值置零（证明与测序零膨胀技术脱扣分布严格同构）。无因果掩码的双向 Transformer 接收时刻 $t$ 的加噪序列 $x_t$，在被掩码的位置索引集 $\mathcal M_t = \{i : x_t^i = \varnothing\}$ 上，通过两个输出头同步优化真实基因身份 $g_i$ 的交叉熵损失与表达量 $v_i$ 的回归均方误差：
   $$\mathcal L_{\text{total}}(\theta) = \mathbb E_{t, x_0, x_t}\!\left[\frac{1}{|\mathcal M_t|}\sum_{i\in\mathcal M_t} -\log p_\theta(g_i\mid x_t, t) + \lambda\cdot\frac{1}{|\mathcal M_t|}\sum_{i\in\mathcal M_t}\big\|\hat v_i - v_i\big\|_2^2\right].$$

### ⚪ **scLDM**：基于置换不变 VAE 与潜空间扩散的单细胞生成模型
- **paper**：[**Scalable Single-Cell Gene Expression Generation with Latent Diffusion Models**](https://openreview.net/forum?id=IRwg87oeJo)

为了在不依赖人为固定基因排序的前提下用 Transformer 生成单细胞离散计数，**scLDM** 提出“可交换 Transformer-VAE + 潜空间流匹配 DiT”两阶段框架：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-051-scldm.png)

第一阶段编码端仅筛选非零表达基因集 $\mathcal J = \{i\in\mathcal I : x_i > 0\}$ 输入以节省算力。架构核心是一个统一的多头交叉注意力模块 $\mathrm{MCAB}_S(X)$（以伪输入矩阵 $S$ 生成 Query $Q$，以输入特征 $X$ 生成 Key/Value $K, V$，计算 $\mathrm{Att}_K(\mathrm{LN}_Q(Q), K, V)$）：
1. **置换不变编码器（Pooling）**：令 $S\in\mathbb R^{m\times D}$ 为固定数量的全局可学习诱导点矩阵，$X$ 为非零基因嵌入。对输入基因施加任意行置换 $P$ 时，因 $Q$ 与输入顺序无关，恒有 $\mathrm{Att}(Q, PK, PV) = \mathrm{Att}(Q, K, V)$，从而将变长无序基因集压缩为固定尺寸且严格置换不变的高斯潜变量 $Z\in\mathbb R^{m\times D}$；
2. **置换等变解码器（Unpooling）**：复用同一模块，但将伪输入替换为按目标查询基因全集索引 $\mathcal I$ 检索的基因身份嵌入矩阵 $S = E_{\mathcal I}$（涵盖零计数基因）去查询潜变量 $Z$，满足 $\mathrm{Att}(PQ, K(Z), V(Z)) = P\,\mathrm{Att}(Q, K(Z), V(Z))$，输出乘以文库大小 $L$ 的负二项（NB）分布均值以重建离散计数。

第二阶段冻结 VAE，在定长潜空间 $Z$ 上训练基于线性插值与流匹配的扩散 Transformer（DiT）速度场 $v_{t,\epsilon}(Z; y)$，并在多属性条件（如“细胞类型 + 扰动”）下采用联合条件标记 $y$ 执行无分类器引导采样：$\tilde v_{t,\epsilon}(Z, y) = v_{t,\epsilon}(Z; \mathrm{Null}) + \omega[v_{t,\epsilon}(Z; y) - v_{t,\epsilon}(Z; \mathrm{Null})]$。

### ⚪ **CountsDiff**：直接在自然数空间建模生灭过程的离散计数扩散
- **paper**：[**CountsDiff: A Diffusion Model on the Natural Numbers for Generation and Imputation of Count-Based Data**](https://openreview.net/forum?id=cvlPAWSeo3)

单细胞 UMI 测序计数取值于无界自然数空间 $\mathbb N_0 = \{0,1,2,\dots\}$：用连续高斯扩散训练后截断会导致严重的零点坍缩，用分类掩码扩散又忽略了数值天然大小序关系。**CountsDiff** 在 Blackout Diffusion 基础上，直接在自然数空间 $\mathbb N_0$ 上构建非齐次生灭过程扩散模型：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-052-countsdiff.png)

1. **余弦调度的二项纯灭前向过程**：将初始计数 $x_0\in\mathbb N_0$ 视为 $x_0$ 个独立粒子，定义单调递减的余弦存活概率调度 $p(t) = \cos^2(\frac{\pi t}{2})$（$t\in[0,1]$，$p(0)=1, p(1)=0$）与瞬时死亡率 $\mu(t) = -p'(t)/p(t)$。代入 Kolmogorov 前向方程即可导出以全零态为终点的精确二项边缘分布与任意时刻 $0\le s < t\le 1$ 的二项转移分布（其信噪比 $\mathrm{SNR}(t) = \frac{p(t)}{1-p(t)}$ 与高斯扩散完全同构）：
   $$q(x_t\mid x_0) = \binom{x_0}{x_t} p(t)^{x_t}\big(1 - p(t)\big)^{x_0 - x_t}, \quad q(x_t\mid x_s) = \binom{x_s}{x_t}\left(\frac{p(t)}{p(s)}\right)^{x_t}\left(1 - \frac{p(t)}{p(s)}\right)^{x_s - x_t}.$$
2. **连续时间散度目标与带损耗的非单调逆向采样**：逆向纯生过程唯一未知的量是已灭失计数 $y_t := x_0 - x_t$。模型用经 Softplus 保证非负的网络输出 $\hat y_t \approx y_t$ 最小化等价于精确连续时间负对数似然（NLL）的加权散度目标：
   $$\mathcal L(\theta) = \mathbb E_{t\sim\mathrm{Unif}(0,1)}\Big[w(t)\big(\hat y_t - y_t\log\hat y_t\big)\Big], \quad w(t) = -p'(t) = \frac{\pi}{2}\sin(\pi t).$$
   为解决纯生逆过程单调递增、一旦预测“超调（overshoot）”便无法回退修正的缺陷，逆向采样步 $t\to s$（$s<t$）引入了损耗率 $\sigma_{t,s}\in[0, \min(1, \frac{1-p(s)}{p(t)})]$ 与伯努利无偏随机舍入值 $\hat y_{\text{clipped}}$，允许已有计数发生二项损耗 $n_t$ 的同时补入补偿性二项新生 $b_t$（严格保持 $x_s$ 的二项边缘分布不变）：
   $$n_t \sim \mathrm{Bin}\big(x_t,\, 1 - \sigma_{t,s}\big), \quad b_t \sim \mathrm{Bin}\!\left(\hat y_{\text{clipped}},\, \frac{p(s) - (1 - \sigma_{t,s})p(t)}{1 - p(t)}\right), \quad x_s = n_t + b_t.$$

### ⚪ **scCBGM**：基于概念瓶颈与流匹配的单细胞反事实编辑
- **paper**：[**scCBGM: Single-Cell Editing via Concept Bottlenecks**](https://openreview.net/forum?id=cVDeFGyb5z)

若要对单个细胞做反事实推理（例如：“保持这颗细胞的个体身份不变，仅将其某个通路活性或药物剂量概念改为 $c'$，其表达谱会如何变化？”），需要显式分离概念与个体背景。**scCBGM** 用编码器推断高斯后验潜变量 $z\sim q(z\mid x)$ 后，经概念瓶颈层将其拆解为受观测概念监督的**已知概念预测 $\hat c = f_c(z)\in\mathbb R^K$**（涵盖二值细胞类型与连续剂量/通路得分）以及捕获个体特异背景的**未知残差因子 $u = f_u(z)\in\mathbb R^{d_u}$**，并在解码器每一层隐藏态中持续拼接跳跃连接 $\hat c$ 以强化概念控制力。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-048-sccbgm.png)

为彻底防止背景因子 $u$ 泄露目标概念信息（且无需像传统正交约束那样限制 $K=d_u$），训练时在大小为 $B$ 的小批量上直接最小化预测概念矩阵 $\hat C\in\mathbb R^{B\times K}$ 与未知因子矩阵 $U\in\mathbb R^{B\times d_u}$（均值分别为 $\mu_{\hat c}, \mu_u$）之间的**经验互协方差矩阵 Frobenius 范数平方**：
$$\mathcal L_{\text{cc}} = \left\|\frac{1}{B-1}\big(\hat C - \mathbf 1\mu_{\hat c}^\top\big)^\top\big(U - \mathbf 1\mu_u^\top\big)\right\|_F^2, \quad \mathcal L = -\mathbb E_{q(z\mid x)}[\log p(x\mid z)] + \lambda_c\mathcal L_{\text{concept}} + \beta\mathrm{KL}\big(q(z\mid x)\,\|\,p(z)\big) + \lambda_{\text{cc}}\mathcal L_{\text{cc}}.$$
在此基础上，进一步将提取的解耦表征 $[u, \hat c]$ 作为条件注入条件流匹配模型（**scCBGM-FM**），学习常微分方程流映射 $\frac{d}{dt}\varphi_t(x_t, [u, \hat c]) = v_\theta(\varphi_t(x_t, [u, \hat c]), t; [u, \hat c])$（$t\in[0,1]$）。推理时严格遵循 Pearl 因果反事实的“溯因—行动—预测”三步法：先在原始概念 $[u, \hat c]$ 条件下沿逆向流 $\varphi_1^{-1}$ 将观测细胞 $x$ 积分映射回外生高斯噪声点 $x_0$（个体级溯因），再保持 $u$ 与 $x_0$ 不变、替换为干预后的概念 $\hat c'$ 正向积分 $\varphi_1$ 生成反事实细胞 $\hat x'$：
$$x_0 = \varphi_1^{-1}\big(x, [u, \hat c]\big) \xrightarrow{\text{Action: }\hat c\to\hat c'} \hat x' = \varphi_1\big(x_0, [u, \hat c']\big).$$

## 5.3 单细胞动力学

<a id="p-077"></a>
### ⚪ **USB**：重建单细胞分裂与凋亡动力学的无模拟非平衡薛定谔桥
- **paper**：[**Beyond Continuity: Simulation-free Reconstruction of Discrete Branching Dynamics from Single-cell Snapshots**](https://openreview.net/forum?id=IABjbJlinz)

单细胞时序快照不仅受内在扩散随机性支配，还伴随细胞增殖分裂与凋亡导致的质量非守恒。**USB** 以扩散系数为 $\nu$、分支速率为 $\lambda$ 的分支布朗运动（BBM）为参考过程构建非平衡薛定谔桥，将演化拆解为带源项连续性方程对应的加权粒子空间位置 $x_t$ 与对数质量 $\ln m_t$：
$$dx_t = \Big(u_t^\circ(x_t) + \frac{\nu^2}{2}s_t(x_t)\Big)dt + \nu dW_t, \qquad d\ln m_t = g_t(x_t)dt.$$
为规避反复积分 NeuralODE 的高昂开销、实现无模拟（simulation-free）训练，方法先对 BBM 增长惩罚函数做二阶泰勒展开，将其静态问题转化为惩罚系数 $\delta = \nu/\sqrt{\lambda}$ 的静态 Wasserstein-Fisher-Rao（WFR）最优熵传输问题，求得两端点间的半耦合分布 $q(z)$（其中 $z=(x_0, x_1)$ 为配对端点，带初始与终末质量 $m_0(z), m_1(z)$）。给定端点对 $z$，构造连接两端的**泊松—布朗桥（Poisson-Brownian Bridge）**条件路径 $m_t(z)\tilde\rho_t(x\mid z)$——空间位置服从高斯布朗桥 $\tilde\rho_t(x\mid z) = \mathcal N(x\mid (1-t)x_0 + t x_1,\, \nu^2 t(1-t)I)$，质量服从指数插值 $m_t(z) = m_0(z)^{1-t}m_1(z)^t$，从而导出闭式条件概率流漂移 $u_t^\circ(x\mid z)$、条件增长率 $g_t(x\mid z) = \ln m_1(z) - \ln m_0(z)$ 与条件得分 $s_t(x\mid z)$，直接最小化以质量 $m_t(z)$ 加权的条件回归目标训练三个网络 $(v_\theta, g_\theta, s_\theta)$（其中 $\lambda(t) = \nu\sqrt{t(1-t)}$）：
$$\mathcal L_{\text{CUSM}}(\theta) = \mathbb E_{t\sim\mathcal U[0,1],\, z\sim q(z),\, x\sim\tilde\rho_t(x\mid z)}\bigg[m_t(z)\Big(\big\|v_\theta(x, t) - u_t^\circ(x\mid z)\big\|_2^2 + \big\|g_\theta(x, t) - g_t(x\mid z)\big\|_2^2 + \lambda^2(t)\big\|s_\theta(x, t) - s_t(x\mid z)\big\|_2^2\Big)\bigg].$$
推理阶段支持单细胞级**离散分支模拟**：每个存活细胞按 Euler-Maruyama 格式更新空间位置，并在时间步 $\Delta t$ 内以概率 $|g_\theta(x, t)|\Delta t$ 触发离散跳变——若 $g_\theta(x,t) \ge 0$ 则原地分裂为两个独立演化的子代细胞，若 $g_\theta(x,t) < 0$ 则发生凋亡移除。

### ⚪ **CellBRIDGE**：用配体—受体细胞通讯先验对齐单细胞发育轨迹
- **paper**：[**CellBRIDGE: Learning Cellular Trajectories via Interaction-Aware Alignment**](https://openreview.net/forum?id=W9EgZALquo)

传统最优传输（OT）对齐单细胞快照时只看基因表达的欧氏距离，将细胞视为孤立粒子而忽略了配体—受体（LR）介导的细胞间通讯（CCI）结构演化平滑性。**CellBRIDGE** 无需空间坐标，直接从解离 scRNA-seq 中经 LIANA 筛选前 $P=10$ 个显著配体—受体对 $\{(l_p, r_p)\}_{p=1}^P$，对细胞 $c$ 基因 $g$ 的归一化表达 $x_{cg}$ 施加 **Hill 饱和函数** $s_{cg} = \frac{x_{cg}^{h_g}}{x_{cg}^{h_g} + \kappa_g^{h_g}}\in[0,1]$（$\kappa_g$ 为非零表达 0.9 分位数），再以发送细胞 $i$ 的配体激活乘接收细胞 $k$ 的受体激活构建快照内有向多通道通讯向量 $g_{i\to k} = [s_{i l_1}s_{k r_1}, \dots, s_{i l_P}s_{k r_P}]^\top \in [0,1]^P$。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-053-cellbridge.png)

在对齐源快照 $\{x_i\}_{i=1}^{n_0}$ 与目标快照 $\{y_j\}_{j=1}^{n_1}$（边缘分布 $a, b$，特征欧氏距离矩阵 $C_{ij}=\|x_i-y_j\|_2^2$）时，通过端点跨度归一化的**多通道有向融合 Gromov-Wasserstein（FGW）**目标，同时最小化基因表达特征位移代价与有向细胞通讯拓扑失真代价：
$$\min_{\Gamma\in\Pi(a,b)} (1-\alpha)\langle\Gamma, C\rangle_F + \alpha\sum_{i,k=1}^{n_0}\sum_{j,\ell=1}^{n_1}\left\|g_{i\to k}^{(0)} - g_{j\to\ell}^{(1)}\right\|_2^2 \Gamma_{ij}\Gamma_{k\ell}.$$
求出的交互感知最优耦合 $\Gamma^\star$ 可直接转化为端点联合分布先验 $\Pi$，无缝接入条件流匹配（CFM）、度量流匹配或无模拟薛定谔桥学习连续轨迹；在推理时直接从配体—受体目录中剔除特定信号轴（如肺癌中的 EGFR、MET）并重算耦合，即可在计算机上模拟靶向阻断细胞通讯引发的发育轨迹偏移。

<a id="p-079"></a>
### ⚪ **LCL**：把谱系条形码作为天然正样本对的单细胞命运对比学习
- **paper**：[**Leveraging Lineage Barcodes as Natural Augmentations for Contrastive Learning of Cell Fate in scRNA-seq Data**](https://openreview.net/forum?id=wqS6MURCFQ)

决定细胞未来分化命运的早期可遗传转录信号非常微弱，很容易被细胞周期或当前细胞类型等主导变异掩盖。**LCL** 利用单细胞谱系追踪（scLT）实验中的慢病毒条形码：把同属一个谱系克隆（携带相同条形码）的两个细胞定义为天然的语义保持“正样本对” $(i,j)\in\mathcal P$，每次从 $N$ 个不同克隆中各抽一对正样本构成大小为 $2N$ 的有标签小批量（不同克隆细胞自然构成负样本）。基因表达向量经编码器与投影头映射为单位球面上的对比嵌入 $z_i$，最小化温度为 $\tau$ 的 NT-Xent 对比损失：
$$\ell(i, j) = -\log\frac{\exp\big(\mathrm{sim}(z_i, z_j)/\tau\big)}{\sum_{k=1}^{2N}\mathbb I_{[k\notin\{i,j\}]}\exp\big(\mathrm{sim}(z_i, z_k)/\tau\big)}, \quad \mathcal L_{\text{contrastive}} = \frac{1}{2N}\sum_{(i,j)\in\mathcal P}\ell(i, j).$$

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-054-lcl.png)

为了将学到的命运决定流形迁移至没有慢病毒条形码的外部常规 scRNA-seq 数据集，每个训练步额外采样 $U$ 个无标签细胞提取嵌入 $\{z_u^{\text{(unl)}}\}_{u=1}^U$，计算其相对于批内 $2N$ 个有标签锚点细胞的余弦软分配概率 $p_{u,k} = \frac{\exp(\mathrm{sim}(z_u^{\text{(unl)}}, z_k)/\tau)}{\sum_{\ell=1}^{2N}\exp(\mathrm{sim}(z_u^{\text{(unl)}}, z_\ell)/\tau)}$，并加上最小化软分配分布香农熵的流形对齐惩罚：
$$\mathcal L_{\text{train}} = \mathcal L_{\text{contrastive}} + \lambda\cdot\frac{1}{U}\sum_{u=1}^U\left(-\sum_{k=1}^{2N} p_{u,k}\log p_{u,k}\right).$$

### ⚪ **STAGE**：基于局部切向对齐与图拉普拉斯的单细胞拟时序排序
- **paper**：[**Trajectory Seriation via Spectral Tangent Alignment and Global Embedding**](https://openreview.net/forum?id=DDNQOnaRQk)

传统拟时序排序方法将高维含噪点云 $\{x_i\in\mathbb R^d\}_{i=1}^n$ 直接坍缩为成对欧氏距离平方矩阵，会导致正交于一维发育流形方向的各向异性噪声平方项累加并淹没真实切向位移。**STAGE** 在半径 $r$ 邻域图（邻接矩阵 $A_{ij} = \mathbb I\{\|x_i - x_j\|_2 \le r\}$，度矩阵 $D_A$，图拉普拉斯 $L = D_A - A$）上分三步恢复全局排序：

1. **局部切向估计**：对每个节点 $i$ 的邻域样本做局部 PCA（经验协方差主特征向量），提取单位局部切线方向估计 $\hat v_i\in\mathbb R^d$；
2. **全局 $\mathbb Z_2$ 谱方向同步**：由于主特征向量存在正负号二义性（$\pm\hat v_i$），在邻域图上求解离散符号同步的球面瑞利商松弛问题 $\hat u = \arg\max_{\|s\|_2^2=n} \sum_{i\sim j} s_i s_j\langle\hat v_i, \hat v_j\rangle$，取符号 $\hat s_i = \mathrm{sign}(\hat u_i)$ 使全图定向切向量 $\hat s_i\hat v_i$ 朝向一致；
3. **有向切向增量与非齐次图拉普拉斯全局嵌入**：将相邻两点位移 $x_j - x_i$ 投影至两端定向切向量的平均方向，构造反对称的局部有向进程增量 $\hat W_{ij} = \frac12(\hat s_i\hat v_i + \hat s_j\hat v_j)^\top(x_j - x_i) = -\hat W_{ji}$（正交于切线方向的噪声在此线性投影下期望抵消为零）。在零均值约束 $\langle\mathbf 1, y\rangle=0$ 下最小化全体边上的增量拟合残差 $\frac12\sum_{i,j}A_{ij}(y_j - y_i - \hat W_{ij})^2 = y^\top L y - 2y^\top\hat\eta$，其中节点净入流散度向量定义为 $\hat\eta_i := \sum_{j=1}^n A_{ij}\hat W_{ji} = -\sum_{j=1}^n A_{ij}\hat W_{ij}$。由一阶最优性条件 $Ly = \hat\eta$，直接通过 Moore-Penrose 伪逆 $L^+$ 得到唯一闭式全局拟时序坐标 $\hat y$：
   $$\hat y = \arg\min_{y\in\mathbb R^n:\langle\mathbf 1, y\rangle=0} \frac12\sum_{i,j:i\sim j}\big(y_j - y_i - \hat W_{ij}\big)^2 = L^+\hat\eta = -L^+\!\left(\sum_{j=1}^n A_{ij}\hat W_{ij}\right)_{i=1}^n.$$

### ⚪ **HDTree**：结合层次树码本与条件扩散的单细胞谱系推断
- **paper**：[**HDTree: Generative Modeling of Cellular Hierarchies for Robust Lineage Inference**](https://openreview.net/forum?id=mURSJDd7hU)

为每个分化分支配置独立网络的树结构 VAE 参数量会随树深指数膨胀。**HDTree** 将网络规模与树拓扑解耦，设计了一个全局共享、最大深度为 $L$ 的满二叉**层次树码本（HTC）** $\mathcal T$（第 $l$ 层包含 $2^l$ 个可学习码向量 $w_j^l\in\mathbb R^d$）。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-055-hdtree.png)

单细胞表达 $x_i$ 经编码器映射为潜表征 $z_i = E_{\theta_E}(x_i)$ 后，从根节点 $\Omega^{(0)}(z_i) = T_0^0$ 出发自顶向下贪心路由：在第 $l\in\{1,\dots,L\}$ 层，仅在上一层选中节点的子节点集合 $\mathrm{Children}(\Omega^{(l-1)}(z_i))$ 中检索欧氏距离最近的码向量，从而将每个细胞量化为一条从粗粒度祖细胞到终末状态的层次码路径 $s_i = [c_{z_i}^1, \dots, c_{z_i}^L]$（其中 $c_{z_i}^l = \Omega^{(l)}(z_i)$）：
$$\Omega^{(l)}(z_i) = \arg\min_{w_j^l\in\mathrm{Children}(\Omega^{(l-1)}(z_i))} \big\|z_i - w_j^l\big\|_2.$$
训练阶段联合优化三项损失：（1）基于局部 KNN 增强视图的双曲空间学生 $t$-分布核软对比损失 $\mathcal L_{\text{SCL}}$；（2）结合停止梯度算子 $\mathrm{sg}(\cdot)$、同时约束样本向码向量对齐与码向量向最近样本 $\Psi_{z_i}(c_{z_i}^l)$ 锚定以防止兄弟节点坍缩的双向层次量化损失 $\mathcal L_{\text{HQL}} = \sum_{l=1}^L \big[A(z_i, c_{z_i}^l) + \lambda A(c_{z_i}^l, \Psi_{z_i}(c_{z_i}^l))\big]$（其中 $A(a,b)=\|\mathrm{sg}(a)-b\|_2^2 + \|a-\mathrm{sg}(b)\|_2^2$）；（3）以完整层次码路径 $s_i$ 为条件的去噪扩散解码器重构损失 $\mathcal L_{\text{DDP}}$。推断发育谱系时，在树父子边基础上补充加深度惩罚的同层 KNN 横向边，搜索起始祖细胞节点到目标终末节点的最短路径即可恢复分化轨迹。

### ⚪ **LGP-OT**：结合潜空间高斯过程与最优传输的纯解码器时序建模
- **paper**：[**Modeling Temporal scRNA-seq Data with Latent Gaussian Process and Optimal Transport**](https://openreview.net/forum?id=8RE5i7g4uB)

在未观测外推时间点上，带编码器的时序模型容易因输入分布偏移而泛化失效。**LGP-OT** 采用**纯解码器（Decoder-only）**深度生成架构：在 $L$ 维潜空间（$L\ll G$）中将第 $l$ 维潜轨迹建模为平滑趋势与时变异方差生物噪声之和 $z_l(t) = f_l(t) + \epsilon_l(t)$，其中 $\epsilon_l(t)\sim\mathcal N(0, \varsigma_l(t)^2)$，并对信号函数 $f_l(t)$ 和对数标准差 $\log\varsigma_l(t)$ 均赋予平方指数核（长度尺度 $\ell$、方差 $\sigma^2$，对应谱密度 $S_{\ell,\sigma}$）的高斯过程（GP）先验。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-056-lgpot.png)

为将精确 GP 的 $\mathcal O(N^3)$ 复杂度降为关于样本数的线性复杂度，方法在有界时间域 $[-J, J]$ 上利用负拉普拉斯算子的前 $M$ 个解析特征值 $\lambda_m = (\frac{\pi m}{2J})^2$ 与正弦特征函数基 $\phi(t) = [\phi_1(t), \dots, \phi_M(t)]^\top$（$\phi_m(t) = \frac{1}{\sqrt J}\sin(\sqrt{\lambda_m}(t+J))$）做希尔伯特空间展开。记变分参数集为 $\Phi = \{A_f, A_\varsigma, \ell_f, \ell_\varsigma, \sigma_f, \sigma_\varsigma\}$（其中基展开权重矩阵行向量服从 $a_{j,l}\sim\mathcal N(0, S_{\ell_{j,l},\sigma_{j,l}}(\sqrt\lambda))$），在时刻 $t$ 采样潜变量并经解码器网络 $h_\theta$ 前推生成预测细胞分布 $\hat\rho_t$：
$$z_i(t; \Phi) = A_f\phi_f(t) + \exp\big(A_\varsigma\phi_\varsigma(t)\big)\odot\xi_{i,t}, \quad \xi_{i,t}\sim\mathcal N(0, I_L), \quad \hat x_{t,i} = h_\theta\big(z_i(t; \Phi)\big) \sim \hat\rho_t.$$
模型完全省去编码器，直接最小化各观测时间点 $t\in\mathcal T$ 上真实细胞快照分布 $\rho_t$ 与生成分布 $\hat\rho_t$ 之间的熵正则化 Wasserstein 距离 $W_{p,\gamma}^p$ 及变分后验 $q_\Psi(\Phi)$ 的 KL 散度：
$$\mathcal L(\theta, \Psi) = \mathbb E_{q_\Psi(\Phi)}\!\left[\sum_{t\in\mathcal T} W_{p,\gamma}^p(\rho_t, \hat\rho_t)\right] + \mathrm{KL}\big(q_\Psi(\Phi)\,\|\,p(\Phi)\big).$$

### ⚪ **MMtSBM**：无配对时序数据的多边缘薛定谔桥匹配
- **paper**：[Multi-marginal temporal Schrödinger Bridge Matching from unpaired data](https://openreview.net/forum?id=LnDNFS8Lea)

给定离散时间网格 $t_0<\dots<t_K$ 上的单细胞快照边缘分布 $\mu_0,\dots,\mu_K$（无跨时间配对轨迹），**MMtSBM** 求解同时命中所有时间点边缘且相对熵最接近参考过程 $Q$ 的多边缘薛定谔桥：
$$P^\star=\arg\min_{P\in\mathcal P(\mathcal C)}\mathrm{KL}(P\,\|\,Q) \quad\text{s.t. }X_{t_k}\sim\mu_k,\ k=0,\dots,K.$$
作者利用静态—动态等价性，将路径分解为“时间网格点上的边缘耦合 + 相邻点之间的参考桥”，提出迭代马尔可夫与互反拟合算法（**IMFF**）交替执行两类投影：（1）**Markovian 投影**：用流匹配/SDE 学习一个共享漂移，使整条分段过程马尔可夫化；（2）**Reciprocal 投影**：固定一侧数据边缘，将每个区间 $[t_i, t_{i+1}]$ 重新填充为参考过程 $Q$ 在端点条件下的局部桥，通过交替迭代逼近全局多边缘薛定谔桥。

### ⚪ **WLM**：从时序快照学习细胞群体的 Wasserstein 拉格朗日力学
- **paper**：[A Call to Lagrangian Action: Learning Population Mechanics from Temporal Snapshots](https://openreview.net/forum?id=MjPv4kRu3H)

一阶流模型（$\dot x = v(x)$）缺乏“惯性”，难以刻画带有动量和阻尼的二阶生物群体动力学。**WLM** 将细胞群体密度曲线 $\rho_t$ 的演化形式化为 Wasserstein 空间中的最小作用量原理，定义带阻尼系数 $\gamma\ge 0$ 的拉格朗日量（动能减群体势能 $U[\rho_t]$）：
$$\mathcal L[\rho_t,s_t] = e^{\gamma t}\left(\frac12\int\|\nabla s_t\|^2\rho_t\,dx-U[\rho_t]\right),$$
其中 $s_t$ 为满足连续性方程 $\dot\rho_t=-\nabla\cdot(\rho_t\nabla s_t)$ 的速度势函数。最小化时间积分作用量可导出 Hamilton-Jacobi 方程 $\dot s_t = -\frac12\|\nabla s_t\|^2 - \frac{\delta U[\rho_t]}{\delta\rho_t} - \gamma s_t$，在微观粒子层面等价于带阻尼的二阶牛顿运动方程：
$$\dot x = v, \qquad \dot v = -\nabla_x\frac{\delta U[\rho_t]}{\delta\rho_t}(x) - \gamma v.$$
WLM 用神经网络参数化群体势能泛函 $U[\rho]$，训练时用蛙跳（Leapfrog）积分器从初始粒子位置与速度滚动模拟轨迹，直接最小化模拟分布与各时刻观测快照之间的 Sinkhorn 散度（当 $\gamma\to\infty$ 过阻尼极限时自然退化为一阶 Wasserstein 梯度流）。

### ⚪ **BGFormer**：用“细胞—锚点”二部图注意力做线性复杂度单细胞聚类
- **paper**：[**Bipartite Graph Attention-based Clustering for Large-scale scRNA-seq Data**](https://openreview.net/forum?id=EVnMERXEvC)

在百万级单细胞数据（$n$ 个细胞，对数归一化高变基因特征 $X\in\mathbb R^{n\times d}$）上构建 $k$-NN 图或计算全细胞自注意力均面临 $\mathcal O(n^2)$ 复杂度瓶颈。**BGFormer** 引入 $m$ 个（$m\ll n$，如 $512\sim 1024$）跨小批量全局共享的可学习**锚点词元 $U=[u_1,\dots,u_m]\in\mathbb R^{m\times d}$**，将细胞间成对交互转化为 $\mathcal O(nm)$ 线性复杂度的“细胞—锚点”二部图注意力：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-057-bgformer.png)

1. **基于 ZINB 重构的全局锚点学习**：先将细胞特征线性投影为 $h_i$，按余弦相似度检索每个细胞的最近邻锚点 $u_i^* = u_{\arg\max_j \cos(h_i, u_j)}$，将 $u_i^*$ 输入零膨胀负二项（ZINB）解码器估计脱扣率 $\pi_i$、离散度 $\theta_i$ 与均值 $\mu_i$，联合最小化原始计数 $\hat x_i$ 的 ZINB 负对数似然与锚点承诺对齐损失：$\mathcal L_a = -\frac1n\sum_{i=1}^n\log\mathrm{ZINB}(\hat x_i\mid\pi_i, \mu_i, \theta_i) + \frac1n\sum_{i=1}^n\|h_i - u_i^*\|_2^2$；
2. **多头二部图注意力与深度嵌入聚类**：在第 $i$ 个注意力头（共 $l$ 个头）中，以细胞特征 $X$ 为 Query、全局锚点 $U$ 为 Key 和 Value 计算二部图注意力矩阵 $B^{(i)}\in\mathbb R^{n\times m}$，拼接多头输出并加跳跃连接生成细胞聚类表征 $Z$，最后结合深度嵌入聚类（DEC）的软分配 KL 散度损失 $\mathcal L_c = \mathrm{KL}(P\,\|\,Q)$ 端到端优化：
   $$B^{(i)} = \mathrm{softmax}\Big(X W_p^{(i)}\big(U W_k^{(i)}\big)^\top\Big), \quad \hat Z_{\text{out}}^{(i)} = B^{(i)} U W_v^{(i)}, \quad Z = \mathrm{concat}\big(\hat Z_{\text{out}}^{(1)},\dots,\hat Z_{\text{out}}^{(l)}\big) + X W_c.$$

### ⚪ **InfoGlobe**：在多项式流形上保持 Fisher-Rao 测地距离的单细胞矩阵分解
- **paper**：[**InfoGlobe: Local-and-Global Information-Preserving Statistical Manifold Learning for Single-Cell Transcriptomics**](https://openreview.net/forum?id=LMrsqvShfy)

常规单细胞预处理在文库大小归一化（映射至概率单纯形 $\Delta^{G-1} = \{p\in\mathbb R_{\ge 0}^G \mid \sum_g p_g = 1\}$）后直接取 $\log(1+x)$ 并在欧氏空间降维，但这存在两个理论缺陷：低丰度端 $p_g\to 0$ 时对数变换的渐近方差发散，且欧氏距离扭曲了单纯形的内蕴统计几何。**InfoGlobe** 将单细胞计数建模为嵌套多项式分布抽样（细胞 $\to$ $K$ 个功能基因程序因子 $\to$ $G$ 个基因）。依据信息几何中的 **Chentsov 定理**，多项式分布族的 Fisher 信息度量通过**平方根拉回映射 $\omega = \sqrt{p}$** 严格等距对应于单位超球面正象限（且平方根变换方差 $\mathrm{Var}[\sqrt{p_g}]\approx\frac{1-p_g}{4n}$ 全局有界），此时两分布间的 **Fisher-Rao 测地距离**直接化简为单位超球面上的大圆弧长：
$$d_{\mathrm{FR}}(p_1, p_2) = \arccos\!\big(\sqrt{p_1}\cdot\sqrt{p_2}\big).$$

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-058-infoglob.png)

给定 $\ell_1$ 归一化后的基因表达矩阵 $X\in\mathbb R_{\ge 0}^{G\times N}$（每列 $x_{\cdot i}\in\Delta^{G-1}$），模型求解同样约束在单纯形上的基因—因子矩阵 $A\in\mathbb R_{\ge 0}^{G\times K}$（$A_{\cdot k}\in\Delta^{G-1}$）与细胞—因子嵌入矩阵 $Z\in\mathbb R_{\ge 0}^{K\times N}$（$z_{\cdot i}\in\Delta^{K-1}$），联合最小化局部 Fisher-Rao 分布重构损失与保持全局成对测地距离的黎曼多维尺度分析（Riemannian MDS）损失：
$$\mathcal L(A, Z) = \sum_{i=1}^N d_{\mathrm{FR}}\big(x_{\cdot i},\, (AZ)_{\cdot i}\big) + \lambda\sum_{i,j}\Big(d_{\mathrm{FR}}(x_{\cdot i}, x_{\cdot j}) - d_{\mathrm{FR}}(z_{\cdot i}, z_{\cdot j})\Big)^2.$$
分解完成后，对每个因子做单因素方差分析（ANOVA）检验其是否与批次标签显著相关，仅对批次相关因子回归减去批次均值偏移并重归一化回 $\Delta^{K-1}$，即可在不损伤生物因子的前提下显式剥离批次效应。

### ⚪ **VBA-Transformer**：先平行移动对齐局部参考系、再算注意力的几何 Transformer
- **paper**：[**VBA: Vector Bundle Attention for Intrinsically Geometric Representation Learning**](https://openreview.net/forum?id=nQ4iLQtsCF)

现有的几何 Transformer 只是在欧氏点积注意力上叠加一个距离位置偏置（“先比较、后加偏置”），但若数据位于弯曲流形上，不同点处的局部特征向量处于不同的局部参考系（纤维空间），直接算内积在几何上并不相容。**VBA-Transformer** 引入微分几何的**向量丛（Vector Bundle）**理论，将每个输入词元 $x_i\in\mathbb R^D$ 投影解耦为底流形坐标 $b_i = W_b x_i\in\mathbb R^{d_b}$ 与经底流形联络曲率 2-形式算子修正后的局部纤维特征 $\bar f_i\in\mathbb R^{d_f}$，提出**“先平行移动对齐、再计算注意力（Align-then-Compare）”**范式：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-059-vba.png)

为避免沿曲线积分联络的高昂开销，对于任意词元对 $(i,j)$，用轻量级网络根据两端底流形坐标 $(b_i, b_j)$ 预测生成元矩阵 $S_{j\to i}\in\mathbb R^{d_f\times d_f}$，经反对称化投影至正交李代数 $\mathfrak{so}(d_f)$ 后，通过矩阵指数映射构造严格位于特殊正交群 $SO(d_f)$ 上的**等距平行移动算子 $T_{j\to i}$**（保持纤维向量范数与内积不变）：
$$S_{\text{skew}}(b_i, b_j) = \frac12\Big(S_{j\to i} - S_{j\to i}^\top\Big), \quad T_{j\to i} = \exp\!\big(S_{\text{skew}}(b_i, b_j)\big) \in SO(d_f).$$
在纤维注意力计算中，由 $\bar f$ 生成 $Q_i, K_j, V_j\in\mathbb R^{d_f}$ 后，先用 $T_{j\to i}$ 将点 $j$ 处的键和值平行移动对齐至点 $i$ 所在的局部纤维坐标系，再执行缩放点积注意力与特征聚合：
$$\tilde K_{j\to i} = T_{j\to i}K_j, \quad \tilde V_{j\to i} = T_{j\to i}V_j, \quad \alpha_{ij} = \mathrm{softmax}_j\!\left(\frac{\langle Q_i,\, \tilde K_{j\to i}\rangle}{\sqrt{d_f}}\right), \quad y_i = x_i + W_o\sum_{j=1}^N \alpha_{ij}\tilde V_{j\to i}.$$

### ⚪ **Tri-Scale Neural ODE**：引入降解阻尼的跨时间尺度多组学神经 ODE
- **paper**：[**Tri-Scale Neural ODEs for Continuous Multi-Omics Disease Modeling**](https://openreview.net/forum?id=PsjSZaunzO)

纵向多组学数据跨越了三个数量级的时间尺度：转录组 $z_g$（小时级，慢）、蛋白质组 $z_p$（分钟级，中）和代谢组 $z_m$（秒级，快），直接用标准神经 ODE 建模会因系统极端刚性（刚性比 $\kappa > 10^6$）而在显式积分时发散。**Tri-Scale Neural ODE** 依据中心法则在导数空间建立单向级联耦合（$z_g \to z_p \to z_m$，可推广至任意 $K$ 层级联），引入满足尺度分离的可学习时间常数 $\tau_g < \tau_p < \tau_m$、消除原点漂移的零中心化参数化 $f_k(z_k, z_{k-1}, t) = \hat f_k(z_k, z_{k-1}, t) - \hat f_k(0,0,t)$ 以及模拟分子一阶降解的线性阻尼项 $-\gamma_k z_k$：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-041-triscale.png)

$$\frac{dz_g}{dt} = \tau_g f_g(z_g, t), \quad \frac{dz_p}{dt} = \tau_p f_p(z_p, z_g, t) - \gamma_p z_p, \quad \frac{dz_m}{dt} = \tau_m f_m(z_m, z_p, t) - \gamma_m z_m.$$
**输入—状态稳定性（ISS）条件**：对于 $K$ 层级联系统，假设根层 $f_1$ 全局 Lipschitz（常数 $L_1$）且 $f_1(0,t)=0$，由 Grönwall 不等式知有限时间区间 $t\in[0,T]$ 内根状态有界 $\|z_1(t)\|\le B_1$；归纳假设上游状态满足 $\sup_{t\in[0,T]}\|z_{k-1}(t)\|\le B_{k-1}$，且第 $k$ 层网络满足关于自身与上游状态的线性增长界 $\|f_k(z_k, z_{k-1}, t)\| \le L_k\|z_k\| + C_k\|z_{k-1}\|$（$L_k, C_k$ 为对应 Lipschitz 常数）。构造二次李雅普诺夫函数 $V_k(z_k) = \frac12\|z_k\|^2$，其沿轨迹的时间导数满足：
$$\frac{dV_k}{dt} = z_k^\top\big(\tau_k f_k(z_k, z_{k-1}, t) - \gamma_k z_k\big) \le -(\gamma_k - \tau_k L_k)\|z_k\|^2 + (\tau_k C_k B_{k-1})\|z_k\|.$$
因此，若满足稳定性条件 **$\gamma_k > \tau_k L_k$**，一旦状态超出半径 $R_k = \frac{\tau_k C_k B_{k-1}}{\gamma_k - \tau_k L_k}$ 的有界球即有 $\frac{dV_k}{dt} < 0$，保证级联系统在 $[0,T]$ 上一致有界且具备输入—状态稳定性。在训练中，模型通过幂迭代计算子网络 $f_k$ 各层权重最大奇异值乘积来估计 $L_k$，并引入带裕度 $\epsilon$ 的谱范数软惩罚项 $\mathcal L_{\text{stab}} = \sum_{k\in\{p,m\}}\max(0, \tau_k L_k - \gamma_k + \epsilon)^2$（与多组学重构损失及相邻层 MINE 互信息最大化项联合优化），在实践中促使网络维持该稳定条件并将有效刚性比降低约三个数量级，从而支持使用显式 Dopri5 求解器稳定积分。

### ⚪ **scChord**：用 ZINB 矫正潜流形再做流匹配的 RNA-蛋白质翻译
- **paper**：[**scChord: A Probabilistic Manifold Rectification Framework for RNA-to-Protein Translation**](https://openreview.net/forum?id=jCKbsTW9m8)

从单细胞转录组（$x_{\text{rna}}$）向蛋白质丰度（$y$）做跨模态翻译时，直接在过分散离散计数上施加强制点对点约束会把测量噪声带入潜空间，导致潜流形曲率爆炸、流匹配速度场变成难积分的刚性 ODE。**scChord** 提出解耦的两阶段框架：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-040-scchord.png)

1. **阶段 1（ZINB 概率流形矫正）**：先在目标蛋白质数据 $y$ 上单独预训练一个以均值 $\mu(z)$、逆离散度 $\alpha=1/\theta$（负二项方差为 $\mu + \alpha\mu^2$）和零膨胀脱扣率 $\pi(z)$ 参数化的 **ZINB 变分自编码器**。理论分析表明，与具有恒定刚度的 MSE 不同，ZINB 负对数似然回传至潜变量 $z$ 的梯度范数受方差自适应缩放因子 $\lambda(\mu,\alpha) = \frac{1}{1+\alpha\mu}$ 与非零生物信号后验置信度 $\gamma(z)\in[0,1]$ 的双重软门控约束：
   $$\|\nabla_z\mathcal L_{\text{ZINB}}\| \le \gamma(z)\cdot\frac{1}{1+\alpha\mu}\cdot\|\nabla_z\mu\|\cdot\|y - \mu\|.$$
   当观测落入高过分散区域（$\alpha\mu$ 大）或高零膨胀脱扣区域（$\pi\to 1 \Rightarrow \gamma\to 0$）时，异常残差梯度被自动衰减截断，使高斯 KL 先验主导优化并将蛋白质计数投影至平滑的矫正潜流形。
2. **阶段 2（稀疏一致性正则化条件流匹配）**：冻结预训练的蛋白质 VAE，从其平滑后验 $q_\phi(z\mid y)$ 中采样传输终点 $x_1$，在标准高斯先验 $x_0\sim\mathcal N(0,I)$ 与 $x_1$ 的直线插值路径 $z_t = (1-t)x_0 + t x_1$ 上训练以 RNA 编码表征 $c=\mathrm{Enc}(x_{\text{rna}})$ 为条件的速度场网络 $v_\theta$；同时对非零 RNA 表达基因施加随机比例掩码构造破损视图 $\tilde x_{\text{rna}}$，联合优化流匹配损失与技术稀疏性不变的一致性正则项：
   $$\mathcal L_{\text{total}} = \mathbb E_{t, x_0, x_1, c}\Big[\big\|v_\theta(z_t, t, c) - (x_1 - x_0)\big\|_2^2\Big] + \lambda_{\text{cons}}\big\|\mathrm{Enc}(x_{\text{rna}}) - \mathrm{Enc}(\tilde x_{\text{rna}})\big\|_2^2.$$

### ⚪ **TACO**：利用跨模态与跨患者解剖拓扑一致性的 3D 医学图像自监督学习
- **paper**：[**Beyond Instance-Level Self-Supervision in 3D Multi-Modal Medical Imaging**](https://openreview.net/forum?id=Vtps0ZUlgv)

不同患者的器官虽有个体形态差异，但相对解剖空间拓扑是恒定的（例如丘脑恒位于基底节内侧）。**TACO** 打破常规自监督学习“单张图像孤立对比”的局限，提出**实例无关跨模态邻域排序一致性（IM-NRC）**：编码器将患者 $h$ 在模态 $i$ 下的 3D 扫描映射为 $K$ 个局部图块（patch）词元 $Z_i^h = \{z_{i,k}^h\}_{k=1}^K$；在源空间 $Z_i^h$ 中特征余弦距离 $d(\cdot,\cdot)$ 互为近邻与非近邻的图块，通过对应关系投射到另一模态或另一患者的目标空间后，应当保持局部近邻比非近邻更近的距离排序。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-038-taco.png)

除单模态自编码重建损失 $\mathcal L_{\text{uni}}$ 外，模型从两个层面构造边际为 $\delta$ 的跨模态三元组铰链损失 $\Big[d(z_{a'}, z_{p'}) - d(z_{a'}, z_{n'}) + \delta\Big]_+$：
1. **实例内跨模态拓扑约束（$\mathcal L_{\text{intra}}$）**：同一患者 $h$ 已配准的不同模态 $(i,j)$ 空间位置严格对齐（对应映射为位置下标恒等映射）。直接在模态 $i$ 内为图块 $a$ 找出特征距离最小的 Top-$\omega$ 个近邻下标与随机抽样的 $\omega$ 个非近邻下标，将这套位置下标直接投射到模态 $j$ 的特征 $z_j^h$ 上计算三元组损失；
2. **实例间跨患者部分拓扑对齐（$\mathcal L_{\text{inter}}$）**：不同患者 $(h, g)$ 在模态 $(i, t)$ 间缺乏像素级配准，方法通过特征空间**互最近邻（MNN）**无监督建立高置信度部分伪对应锚点集 $V_{i,t}^{h,g}$（当且仅当两图块互为对方在跨患者特征空间中的最近邻时才建立对应）：
   $$V_{i,t}^{h,g} := \Big\{(a, a') \;\Big|\; a = \arg\min_o d\big(z_{i,o}^h,\, z_{t,a'}^g\big),\; a' = \arg\min_o d\big(z_{i,a}^h,\, z_{t,o}^g\big)\Big\}.$$
   仅在落入可靠锚点集 $V_{i,t}^{h,g}$ 的图块子集上，将患者 $h$ 模态 $i$ 的邻域/非邻域关系映射至患者 $g$ 模态 $t$ 计算跨实例三元组损失。

### ⚪ **M-IDoL**：用 MoE 分离模态特异信息与共享信息的医学视觉预训练
- **paper**：[**M-IDoL: Information Decomposition for Modality-Specific and Diverse Representation Learning in Medical Foundation Model**](https://openreview.net/forum?id=pn5lQVm3DH)

把 CT、MRI、X 光等异构医学图像混入单一空间做常规对比学习，模型往往只保留跨模态共享的粗糙信息，削弱了各模态特有的病理细节。对图像生成 $M$ 个增强视图，设孪生编码器（学生 $S_\theta$ 与 EMA 教师 $T_\theta$）提取的同模态表征对为 $X, Y$，批次内其他异构模态图像表征为 $Z$。**M-IDoL** 的目标是最大化同模态互信息 $I(X; Y)$ 并剔除三元跨模态共享冗余 $I(X; Y; Z)$，经互信息与条件熵恒等式严格转化为两个条件熵目标：
$$\max\; I(X; Y) - I(X; Y; Z) \iff \max\; H(X\mid Z) - H(X\mid Y, Z).$$

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-037-midol.png)

为了在无模态标签的混洗批次中实现该分解，在学生和教师编码器后接一个含 $N$ 个专家的 **Top-1 混合专家（MoE）投影器**（路由概率向量分别为 $a_S^j, a_T^j\in\mathbb R^N$）：
1. **最大化模态间条件熵 $H(X\mid Z)$（路由一致性损失 $\mathcal L_{\text{route}}$）**：对教师路由概率施加 Sinkhorn-Knopp 双随机归一化以强制批次内专家负载均衡、防止路由坍缩，并最小化同一图像不同增强视图 $(j, \gamma)$ 间的跨分支路由交叉熵，将不同模态自动推入统计独立的专家子空间：
   $$\mathcal L_{\text{route}} = -\frac{1}{M(M-1)}\sum_{j=1}^M\sum_{\substack{\gamma=1 \\ \gamma\neq j}}^M\sum_{i=1}^N a_S^{(j,i)}\log a_T^{(\gamma,i)};$$
2. **最小化模态内条件熵 $H(X\mid Y, Z)$（子空间内对比损失 $\mathcal L_{\text{cst}}$）**：在每个专家子空间 $i$ 分配到的图像子集 $B_i$ 内部，独立计算消除增强噪声的多视图 InfoNCE 对比损失 $\mathcal L_{\text{cst}}^i$。预训练完成后丢弃两侧 MoE 投影器，仅保留教师视觉编码器用于下游多模态任务。

### ⚪ **Foundation VAE**：直接复用冻结的自然视频 VAE 做 3D CT 重建与生成
- **paper**：[**Foundation VAEs for CT Reconstruction, Augmentation, and Generation**](https://openreview.net/forum?id=f51haqkwRQ)

从头训练 3D 医学 CT 专属的 VAE 计算开销大，且容易在不同扫描仪与病种间发生过拟合。这篇工作直接复用在大规模自然图像与视频上预训练并**完全冻结的视频自编码器（Foundation VAE，编码器 $E$、解码器 $D$）**作为统一潜空间接口处理 3D CT 体积 $x$：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-036-vaect.png)

1. **零样本边界保持去噪与分割视图增强**：直接调用冻结视频 VAE 执行零样本重建 $\tilde x := T(x) = D(E(x))$。由于信息瓶颈主要衰减软组织中的高频采集颗粒噪声而完整保留解剖边缘，可将 $(\tilde x, y)$ 直接作为零成本增强视图训练下游分割器 $f_\theta$。理论上，若任务相关特征映射 $\phi$ 满足期望重建稳定性 $\mathbb E[\|\phi(x)-\phi(T(x))\|_2]\le\varepsilon_\phi$ 且损失为 $L_\ell$-Lipschitz，则在重建分布 $T_\# P$ 上训练所得参数 $\hat\theta$ 相对于真实分布最优参数 $\theta^\star$ 的超额分割风险满足显式上界 $R_P(\hat\theta) - R_P(\theta^\star) \le 2 L_\ell \varepsilon_\phi$；
2. **双条件受控潜扩散生成**：在同一冻结编码器的潜空间 $z_0 = E(x)$（前向加噪为 $z_t$）中训练去噪 U-Net $\epsilon_\theta$。将全身多器官解剖掩码 $m_{\text{org}}$ 与指定病灶掩码 $m_{\text{dis}}$ 拼接为 $m = [m_{\text{org}}, m_{\text{dis}}]$，同样复用冻结编码器 $E(m)$ 投影至对齐的潜空间坐标与 $z_t$ 按通道拼接，配合冻结文本编码器提取的放射学报告语义 $r$ 引导生成；同时在潜空间特征张量的轴向切片深度维 $f$ 上附加一层初始化为 Dirac delta 恒等映射（中心权重为 1、邻近偏移为 0）的一维局部卷积 $Y_{b,c,f,h,w} = \sum_{\tau} w_{c,\tau} X_{b,c,f+\tau,h,w}$，以保证冠状面与矢状面的跨切片三维解剖连续性：
   $$\mathcal L = \mathbb E_{x, \epsilon, t, m, r}\Big[\big\|\epsilon - \epsilon_\theta\big([z_t; E(m)], r, t\big)\big\|_2^2\Big].$$

### ⚪ **Cello**：结合蛋白荧光监督与跨层级注意力校准的病理切片分析

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-035-cello.png)

2. **可扩展局部原型与全局 MIL 注意力校准**：在局部模块中，将 $\mathrm{CLS}_k^{\text{HE}}$ 投影为单位向量 $v_k$，为 $S$ 类病灶中的每一类 $s$ 维护 $R$ 个可训练单位原型 $\{\hat\mu_{s,r}\}_{r=1}^R$，计算第 $k$ 个图块跨所有病灶类别的最大原型匹配分 $e_k = \max_{s\in\{1,\dots,S\}}\max_{r\in\{1,\dots,R\}}(v_k^\top\hat\mu_{s,r})$ 作为该图块的显式局部病灶证据强度。在全局门控注意力 MIL 模块中（原始注意力 logit 为 $\xi_k$），以系数 $\rho\ge 0$ 将局部证据 $e_k$ 直接注入全局 logit 得到校准注意力权重 $\bar\omega_k$，并通过最小化 KL 散度 $\mathcal L_{\text{lg}}$ 强制全局决策路由对齐局部病灶证据（同时将局部原型对比损失梯度回传至图块内细胞级聚合层）：
   $$\bar\xi_k = \xi_k + \rho e_k, \qquad \bar\omega_k = \frac{\exp(\bar\xi_k)}{\sum_{k'=1}^K\exp(\bar\xi_{k'})}, \qquad \mathcal L_{\text{lg}} = \mathrm{KL}\big(\mathrm{softmax}_k(e_k)\,\|\,\bar\omega\big).$$

### ⚪ **RNA-FM**：用通路图注意力与流匹配从病理切片预测 Bulk RNA-Seq
- **paper**：[**RNA-FM: Flow-Matching Generative Model for Genome-wide RNA-Seq Prediction**](https://openreview.net/forum?id=v5dquZIEUt)

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-034-rnafm.png)

若两个通路存在重叠基因，则在通路图邻接矩阵中连边并构造注意力掩码 $M$，在扩散 Transformer（DiT）骨干中执行多头通路图自注意力。输出端，各通路词元分别经预测头输出所属基因的表达量 $\hat x_{P_i}\in\mathbb R^{|P_i|}$，背景词元输出 $\hat x_B\in\mathbb R^{|B|}$；由于单个基因 $g$ 可同时归属于多个功能通路，按基因在各集合中的局部索引 $\mathrm{idx}_i(g)$ 执行重叠计数平均以还原全基因组向量 $\hat x\in\mathbb R^G$：
$$\hat x_g = \frac{\sum_{i:\,g\in P_i} \hat x_{P_i,\,\mathrm{idx}_i(g)} + \mathbb I[g\in B]\,\hat x_{B,\,\mathrm{idx}_{\text{bg}}(g)}}{\sum_{i:\,g\in P_i} 1 + \mathbb I[g\in B]}.$$
模型以病理切片图块经 UNI 编码并做 K-means 聚类得到的紧凑形态表征 $y\in\mathbb R^{K\times d}$ 为条件，在标准高斯先验 $x_0\sim\mathcal N(0,I_G)$ 与目标表达 $x_1$ 的插值路径 $x_t = \alpha(t)x_1 + \sigma(t)x_0$（线性调度下 $\alpha(t)=1-t,\ \sigma(t)=t$）上最小化条件流匹配损失 $\mathcal L_{\text{RNA-FM}}(\theta) = \mathbb E_{x_0,x_1,t}\big[\|v_\theta(x_t, t\mid y) - (\dot\alpha(t)x_1 + \dot\sigma(t)x_0)\|^2\big]$。

### ⚪ **FLAG**：结合空间图条件与基因基础模型对齐的空间转录组扩散生成
- **paper**：[**FLAG: Foundation model representation with Latent diffusion Alignment via Graph for spatial gene expression prediction**](https://openreview.net/forum?id=yY7rywRtlI)

从常规 H&E 病理切片生成空间转录组（$N$ 个捕获点 $\times$ $G$ 个基因）时，如果同时对节点基因表达 $X_t\in\mathbb R^{N\times G}$ 和捕获点间功能相关性边 $A_t\in\mathbb R^{N\times N}$ 执行联合图扩散，理论分析表明：随着基因维度 $G$ 增大，样本相关性矩阵围绕总体矩阵集中，导致条件边分布 $p(A_t\mid X_t)$ 的协方差最小特征值按 $\lambda_{\min} \le C/G$ 收缩，使得条件边缘得分函数 $\nabla_{A_t}\log p(A_t\mid X_t)$ 的 Fisher 信息矩阵最大特征值随基因数线性发散（$\lambda_{\max} \ge cG$），引发高维梯度爆炸（“基因维度灾难”）。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-033-flag.png)

为此，**FLAG** 摒弃动态边扩散，改用捕获点二维坐标 $u_i$ 的高斯距离核与预训练病理视觉编码器（UNI）特征 $v_i$ 的余弦相似度预计算**静态双通道边属性** $C_{e,ij} = \big[\exp(-\frac{\|u_i - u_j\|_2^2}{2\sigma^2}),\, \mathrm{CosSim}(v_i, v_j)\big]$，经边调制图注意力编码器提取对基因维度 $G$ 数值稳定的空间上下文条件 $C_{\text{graph}}$；同时在沿基因维交互的扩散 Transformer（DiT）第 $k$ 个中间层隐状态 $H^{(k)}\in\mathbb R^{B\times G\times d_h}$ 上，对齐离线提取的冻结单细胞基因基础模型（Geneformer）上下文基因嵌入 $F\in\mathbb R^{G\times d_e}$：
$$\mathcal L_{\text{total}} = \mathbb E_{t, X_0, z}\Big[\big\|s_\theta(X_t, t, C_{\text{graph}}) - \nabla_{X_t}\log p_t(X_t\mid X_0)\big\|_2^2\Big] - \lambda_{\text{align}}\frac{\big\langle\mathrm{MLP}(H^{(k)}),\, F\big\rangle}{\|\mathrm{MLP}(H^{(k)})\|_2\,\|F\|_2 + \epsilon}.$$
此外，论文还提出了评估基因间共表达相关矩阵上三角相关性的 **GSC**，以及基于空间 $k$-NN 二值权重矩阵 $W$ 计算各基因全局莫兰指数（Moran's I：$I(g) = \frac{N}{\sum_{i,j}W_{ij}}\frac{z_g^\top W z_g}{z_g^\top z_g}$）跨基因相关性的 **SSC** 两项结构保真度指标。

### ⚪ **HEXST**：直接在六边形网格上做平移窗口注意力的空间转录组预测
- **paper**：[**HEXST: Hexagonal Shifted-Window Transformer for Spatial Transcriptomics Gene Expression Prediction**](https://openreview.net/forum?id=UwPbsFk2Dh)

10x Visium 等空间转录组芯片的捕获点是按**六边形晶格**排列的，强行假设为笛卡尔方形网格会破坏各向同性的邻域几何。**HEXST** 根据捕获点间距将归一化二维坐标转换为满足零和约束的三维整数立方坐标 $(u_i, v_i, w_i)\in\mathbb Z^3$（$u_i + v_i + w_i = 0$），直接在六边形晶格上划分多尺度平移窗口并按相对窗口中心的局部立方偏移 $(\Delta u, \Delta v, \Delta w)$ 打包槽位。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-031-hexst.png)

为了在六边形窗口自注意力中保持平移等变性，作者将单头查询/键特征通道均分为对应三个立方主轴的子向量 $h=[h^{(u)}; h^{(v)}; h^{(w)}; h^{(\text{rem})}]$，对每个主轴 $\alpha\in\{u,v,w\}$ 按局部坐标偏移 $\Delta\alpha$ 与基频 $\omega_k$ 定义的旋转角 $\theta_k^{(\alpha)} = \Delta\alpha\cdot\omega_k$ 施加二维正交旋转，提出了**六边形旋转位置编码（HexRoPE）**。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-032-hexrope.png)

输出端由捕获点隐表征 $z_i$ 预测绝对表达 $\hat Y\in\mathbb R^{N\times G}$。为防止稀疏基因回归坍缩至局部均值并抹平肿瘤边界，模型额外引入一个独立的偏差预测头，从批内中心化隐特征 $z_{i,d}^\Delta = z_{i,d} - \bar\mu_d$ 预测局部表达偏差 $\bar y_i^\Delta$；将其与中心化真实表达 $y_{i,g}^\Delta = y_{i,g} - \mu_g$ 分别按各自基因标准差 $\sigma_g(\cdot)$ 标准化为 $\tilde{\bar y}_{i,g}^\Delta$ 与 $\tilde y_{i,g}^\Delta$ 后构造偏差匹配损失 $\mathcal L_{\text{DEV}}$，与点级均方误差 $\mathcal L_{\text{MSE}}$、基因级皮尔逊相关损失 $\mathcal L_{\text{PL}}$ 及训练期单细胞基础模型（scFoundation）先验嵌入 $t_i$ 的余弦对齐损失 $\mathcal L_{\text{TFA}}$ 联合优化：
$$\mathcal L = \lambda_{\text{MSE}}\mathcal L_{\text{MSE}} + \lambda_{\text{PL}}\mathcal L_{\text{PL}} + \lambda_{\text{TFA}}\frac1N\sum_{i=1}^N\left(1 - \frac{p(z_i)^\top t_i}{\|p(z_i)\|_2\,\|t_i\|_2}\right) + \lambda_{\text{DEV}}\frac{1}{NG}\sum_{i=1}^N\big\|\tilde y_i^\Delta - \tilde{\bar y}_i^\Delta\big\|_2^2.$$

### ⚪ **HiST**：基于稀疏晶格多尺度注意力与切片校准词元的空间转录组预测
- **paper**：[**HiST: A Hierarchical Sparse Transformer for Cross-Modal Spatial Transcriptomics Modeling**](https://openreview.net/forum?id=ptbzlHzmEv)

组织病理切片上的有效测量位点呈稀疏不规则分布，且不同切片间存在明显的染色与扫描仪批次偏移。**HiST** 通过无碰撞整数网格映射将 $N$ 个测量位点投影至二维离散晶格 $\mathcal L$，构建仅在非空观测支撑集 $\mathcal M=\{(i_n, j_n)\}_{n=1}^N$ 上运算的二进多尺度编码—解码架构（第 $\ell$ 层计算复杂度严格正比于活跃位点数 $\mathcal O(N_\ell)$）。

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-029-hist.png)

1. **双路径单尺度精炼**：在每个尺度层级，活跃位点特征矩阵 $X\in\mathbb R^{N_\ell\times d}$ 通过局部与全局两条并行路径更新 $X' = X + \mathrm{Proj}\big(\mathrm{W\text{-}MSA}(X) + \mathrm{MCA}(X, C_b)\big)$——**稀疏平移窗口自注意力（W-MSA）**利用常数时间查找表仅收集窗口内的非空活跃词元算带二维相对位置偏置的局部注意力；**低秩切片分布校准（MCA）**引入跨切片共享的可学习全局瓶颈词元 $C_b\in\mathbb R^{1\times d}$，先通过全局注意力读取当前切片所有位点特征以吸收切片级染色与批次偏移，再通过交叉注意力向全体组织词元广播校准偏置：
   $$\mathrm{MCA}(X, C_b) = \mathrm{Attn}(X W_Q,\, C_b W_K,\, C_b W_V;\, 0), \quad C_b \leftarrow C_b + \mathrm{Attn}\big(C_b W_Q^{(c)},\, [X; C_b]W_K^{(c)},\, [X; C_b]W_V^{(c)};\, 0\big).$$
2. **二进粗化与反粗化多尺度转换**：模仿拉普拉斯金字塔，编码器通过 $2\times 2$ 子槽位非空指示符 $m_{u,v,\delta}\in\{0,1\}$ 与槽位特异权重 $W_\delta^{(\ell)}$ 将活跃位点聚合至父节点 $(u,v) = (\lfloor i/2\rfloor, \lfloor j/2\rfloor)$（粗化：$x_{u,v}^{(\ell+1)} = \sum_{\delta\in\{0,1\}^2} m_{u,v,\delta} W_\delta^{(\ell)} x_{2u+\delta_1, 2v+\delta_2}^{(\ell)}$，每级活跃词元数缩减约 1/4）；解码器则将父词元通道扩展 4 倍后仅向非空活跃子位点散射回填，并与编码器同尺度特征横向拼接精炼。

### ⚪ **MoLF**：在基因 VAE 潜空间做混合专家流匹配的泛癌种空间表达预测
- **paper**：[**MoLF: Mixture-of-Latent-Flow for Pan-Cancer Spatial Gene Expression Prediction from Histology**](https://openreview.net/forum?id=SNRYGh6n69)

跨多个癌种从 H&E 病理图像预测空间基因表达时，不同组织形态异质性极强，单一共享权重的生成模型容易发生梯度干扰。**MoLF** 提出两阶段混合潜空间流框架：第一阶段先用 Transformer VAE（编码器 $q_\phi$、MLP 解码器 $f_\psi$）将高维基因表达 $x$ 压缩至捕获协同生物程序的低维潜空间，收敛后冻结；第二阶段在标准高斯先验 $z_0\sim\mathcal N(0,I)$ 与目标基因潜表征 $z_1$ 的线性插值路径 $\psi_t(z_0, z_1) = (1-t)z_0 + t z_1$（$t\in[0,1]$，目标恒定速度 $u_t = z_1 - z_0$）上做条件流匹配，将速度场参数化为 $N$ 个 Transformer 专家网络 $\{E_i\}_{i=1}^N$ 的 **Top-$k$ 稀疏混合专家（MoE）**，以病理图像特征（UNI-v2）和独热癌种标签 $c=\{c_{\text{img}}, c_{\text{type}}\}$ 为条件动态路由：
$$v_\theta(z_t, t, c) = \sum_{i=1}^N G(z_t, t, c)_i \cdot E_i(z_t, t, c).$$

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-028-molf.png)

为保证潜空间轨迹终点落在有效的转录组流形上并防止专家坍缩，训练时将当前状态单步外推至终点估计 $\hat z_1 = z_t + (1-t)v_\theta(z_t, t, c)$，经冻结的第一阶段解码器 $f_\psi$ 还原后施加基因重构损失，并与流匹配损失及批次路由负载均衡损失 $\mathcal L_{\text{aux}}$ 联合优化：
$$\mathcal L_{\text{total}} = \lambda_{\text{flow}}\mathbb E_{t, z_0, z_1}\Big[\big\|v_\theta(\psi_t, t, c) - (z_1 - z_0)\big\|^2\Big] + \lambda_{\text{gene}}\big\|x - f_\psi(\hat z_1)\big\|_2^2 + \lambda_{\text{aux}}\mathcal L_{\text{aux}}.$$
推理时采用无分类器引导（CFG）；针对高引导尺度 $w$ 虽提升相关系数但易引发幅值放大失真的问题，提出“过滤—排序”协议：先筛选使预测与真实表达间 1-Wasserstein 分布距离满足容差阈值的候选尺度集，再从中选取余弦距离最小的 $w^*$。

### ⚪ **SpatialWhisperer**：以基因表达为桥梁实现病理切片的零样本图文注释
- **paper**：[**Transitive Representation Learning Enhances Histopathology Annotation**](https://openreview.net/forum?id=Ze7U293Zw4)

组织病理学图像缺乏细胞级细粒度文本标注（即缺少直接的“图像—文本”配对 $\mathcal I\leftrightarrow\mathcal T$），但我们拥有空间转录组数据（图像—基因配对 $\mathcal I\leftrightarrow\mathcal G$）和单细胞转录组图谱（基因—文本注释配对 $\mathcal G\leftrightarrow\mathcal T$）。**SpatialWhisperer** 以基因表达 $\mathcal G$ 为共享桥接模态，将病理图像块编码器（UNI 2）、基因编码器（Geneformer）与生物医学文本编码器（BioBERT）经两层 MLP 投影头映射至同一单位超球面，输出归一化嵌入 $z^{\mathcal I}, z^{\mathcal G}, z^{\mathcal T}$，在两组不相交的配对数据上联合优化对称 InfoNCE 对比损失（锁定图像与基因主干，仅更新文本主干与全部投影头）：
$$\mathcal L = \lambda_{\mathcal I\leftrightarrow\mathcal G}\mathcal L_{\mathcal I\leftrightarrow\mathcal G} + \lambda_{\mathcal T\leftrightarrow\mathcal G}\mathcal L_{\mathcal T\leftrightarrow\mathcal G}, \quad \mathcal L_{\mathcal X\leftrightarrow\mathcal Y} = -\log\frac{\exp(\langle z^{\mathcal X}, z^{\mathcal Y}\rangle/\tau)}{\sum_k\exp(\langle z^{\mathcal X}, z_k^{m_k}\rangle/\tau)}.$$

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-027-spatialwhisperer.png)

论文从理论上建立了**传递表征学习（Transitive Representation Learning）**的显式上界：以桥接嵌入 $z_i^{\mathcal G}$ 为参考轴做正交分解，若观测模态对满足正样本紧致性 $\langle z_i^{\mathcal I}, z_i^{\mathcal G}\rangle \ge 1-\epsilon$、$\langle z_i^{\mathcal G}, z_i^{\mathcal T}\rangle \ge 1-\epsilon$ 且负样本排斥 $\le \eta$，则由 Cauchy-Schwarz 不等式可导出未观测模态对（$\mathcal I\to\mathcal T$）的正样本内积下界 $s^+ = \langle z_i^{\mathcal I}, z_i^{\mathcal T}\rangle \ge 2(1-\epsilon)^2 - 1 := p(\epsilon)$ 及负样本内积上界 $s_k^- \le \max\{\eta, (1-\epsilon)\eta\} + \sqrt{2\epsilon-\epsilon^2} := q(\epsilon,\eta)$，使得未观测模态对的 InfoNCE 损失严格受控于 $\ell_i \le \log(1 + N e^{(q(\epsilon,\eta) - p(\epsilon))/\tau})$。推理时直接计算常规 H&E 图像块嵌入与候选细胞类型文本嵌入的内积即可完成零样本注释。

   $$\begin{aligned}
   &\mathcal L = \mathbb E_\lambda\Big[w\big\|v_\theta(\ell_\lambda, \lambda\mid z_{\text{cond}}) - u\big\|_2^2\Big] + \rho\mathcal L_{\text{cond}} + \lambda_{\text{morph}}\mathrm{SWD}(\mathcal D_{\text{gen}}, \mathcal D_{\text{real}}),\\
   &\text{where }\; \mathcal L_{\text{cond}} = \mathbb E_\lambda\Big[\big\|v_\theta(\ell_\lambda, \lambda\mid z_{\text{cond}}) - u\big\|_2^2 - \big\|v_\theta(\ell_\lambda, \lambda\mid z_{\text{cond}}^-) - u\big\|_2^2\Big]_+.
   \end{aligned}$$

### ⚪ **SpaEF**：利用大模型语义构图与逐元素自编码器的空间转录组去噪
- **paper**：[SpaEF: Spatially Resolved Transcriptomics Data Element-Wise Denoising Framework Powered by Large Models](https://openreview.net/forum?id=QO1uZg4fj4)

空间转录组表达矩阵 $B\in\mathbb R^{M\times N}$（$M$ 个捕获点、$N$ 个基因）具有高稀疏性与零膨胀特性；传统去噪方法依赖易受染色伪影干扰的组织学图像构建捕获点图、仅靠线性相关构建基因图，且对双图输出仅做粗粒度标量加权。**SpaEF** 引入冻结的大模型语义先验建图，并通过逐元素图自编码器（EGAE）执行细粒度去噪：

![](https://pub-c304ca0128b34bff97119b39961bc4f0.r2.dev/ai4s-conf-icml26-025-spaef.png)

1. **结合 OmiCLIP 语义的捕获点图构建（SGC）**：无需组织学图像，将每个捕获点 $i$ 中表达量最高的前 $k_e$ 个非管家基因名称拼接为“捕获点句子”，输入冻结的跨模态预训练 **OmiCLIP** 文本编码器获取语义嵌入，在 Delaunay 三角剖分初始空间图上训练 GAT 图自编码器提取低维表示 $\tilde z_i^a$，进而选取余弦相似度最高的前 $k_s$ 个节点构建捕获点图 $G_s$；
2. **融合 GenePT 功能语义与共表达的基因图构建（GGC）**：将每个基因的 NCBI 功能文本描述输入冻结的 **GenePT** 提取语义向量 $t_i$ 并调用其预训练逻辑回归头推断基因对功能互作概率 $p_{i,j}$；仅当基因 $j$ 同时属于基因 $i$ 的皮尔逊共表达 Top-$k_g$ 候选集 $P_i^g$ 且满足 $p_{i,j} > \tau$ 时才连接基因边（$A_{i,j}^g = \mathbf{1}[j\in P_i^g \land p_{i,j} > \tau]$），构建基因图 $G_g$；
3. **逐元素门控融合与 ZINB 损失优化（EGAE）**：分别在捕获点图 $G_s$ 和基因图 $G_g$ 上运行独立的 GAT 特征自编码器，输出捕获点视角去噪矩阵 $B^s\in\mathbb R^{M\times N}$ 与基因视角去噪矩阵 $B^g\in\mathbb R^{N\times M}$。随后通过可学习的**矩阵级逐元素权重 $W\in\mathbb R^{M\times N}$**（$\sigma(\cdot)$ 为 Sigmoid 函数）自适应门控融合双视角结果得到去噪表达矩阵 $\hat B$，并将其视为零膨胀负二项（ZINB）分布的均值矩阵 $\mu$（配合零膨胀率 $\pi_{i,j}$ 与基因离散度 $\theta_j$），端到端最小化原始表达 $b_{i,j}$ 的 ZINB 负对数似然与均值正则项：
   $$\mathcal B_{i,j} = W_{i,j}\big(B_{i,j}^s + B_{j,i}^g\big), \quad \hat B = \sigma(\mathcal B)\odot B^s + \big(1 - \sigma(\mathcal B)\big)\odot (B^g)^\top, \quad \mathcal L_Z = -\sum_{i,j}\log P_{\mathrm{ZINB}}\big(b_{i,j}\mid \mu_{i,j},\theta_j,\pi_{i,j}\big) + \frac{\lambda}{MN}\sum_{i,j}\mu_{i,j}^2.$$
